# 设置菜单

> 版本：MVP v2.6 | 状态：✅ 已实现 | 最后更新：2026-07-17

## 触发方式

点击 TopBar 右侧 ⚙ 设置按钮，或在战斗中通过设置按钮呼出。

## 菜单结构

```
┌──────────────────────┐
│       设置           │
│                      │
│  画面分辨率          │
│  [1920×1080（推荐）▼]│
│  ────────────────    │
│  [返回标题界面]       │
│  [退出游戏]          │
└──────────────────────┘
```

## 功能项明细

| 功能 | 类型 | 说明 |
|------|------|------|
| 画面分辨率 | OptionButton | 切换：1920×1080 / 1600×900 / 1280×720。通过统一 `ResolutionSettings` 实际应用窗口/viewport，成功后保存用户设置 |
| 返回标题界面 | Button | 返回到 Title 场景 |
| 退出游戏 | Button | `GetTree().Quit()`，直接关闭程序 |

## 技术实现

- 代码文件：`scripts/UI/SettingsHelper.cs`、`scripts/UI/ResolutionSettings.cs`
- 共享方式：静态工具类 `SettingsHelper.Show(Node parent)`，MapController 和 BattleController 通过 TopBar.OnSettingsPressed 回调调用
- 分辨率切换：当前只正式支持 `1920×1080`、`1600×900`、`1280×720` 三档 16:9 宽屏桌面分辨率。选择后立即请求应用；仅在实际窗口/viewport 成功变更后才记录为成功值。
- 持久化：最后一次成功设置保存到用户配置，并在场景切换、重新打开设置和重启后恢复；关闭设置只关闭 UI，不回滚已经成功应用的分辨率。
- 失败处理：不支持的尺寸、headless 环境或 OS 拒绝应用时，保留并回显上一次实际生效值，显示可读失败原因；不得保留下拉框已切换但窗口未改变的假成功状态。
- 适配边界：本轮不提供窗口模式/全屏模式切换；但已支持三档分辨率的真实窗口与 viewport 适配。低于 `1280×720` 或非受支持比例必须禁用或明确提示，不得通过压缩 UI 伪装支持。
