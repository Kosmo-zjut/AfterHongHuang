# 00-UI交互总览

> 版本: 1.1.3 | 状态: ✅ MVP / Act1 UI 壳层、节点外置地图入口与胜利模态契约 | 最后更新: 2026-07-17

---

## 1. 设计原则

| 原则 | 说明 |
|------|------|
| **直觉优先** | 玩家无需阅读教程即可理解操作。MVP 阶段卡牌点击后上浮=已选中，目标高亮/箭头=可打 |
| **反馈即时** | 每次操作都有视觉/音效反馈：选中卡牌有上浮/箭头提示、伤害有飘字、按钮有按感 |
| **信息分层** | 节点通用信息前置（生命/永久资源/套牌摘要）；BattleNode 额外显示当前回合灵力与战斗状态，次要信息折叠（buff详情/tooltip展开） |
| **洪荒气质** | 界面语言保持水墨厚涂风格，UI组件使用毛笔笔触边角、沉郁色调，拒绝高饱和扁平化 |

## 2. 操作模型

### 2.1 主要操作方式

| 操作 | 方式 | 说明 |
|------|------|------|
| **出牌（MVP）** | 鼠标点击/按住拖动 | 敌方目标牌显示从卡牌指出的上凸箭头；默认自身/无目标牌点击或长按进入持牌状态，移出手牌区后点击/释放确认 |
| **取消出牌（MVP）** | 再点同牌 / 右键 / 点空白 | 取消选中，卡牌回到底部手牌区 |
| **持牌拖拽（补充）** | 长按鼠标拖动 | 拖到合法目标/区域后释放确认；非法释放回弹取消，与点击持牌状态共用反馈 |
| **选择选项** | 鼠标点击 | 道痕3选1、卡牌奖励3选1、灵脉节点选项等 |
| **结束回合** | 点击按钮 | 右下角"结束回合"按钮 |
| **查看详情** | 鼠标悬停 | 悬停在任何 UI 元素上弹出 tooltip（buff/debuff/卡牌/道痕） |

### 2.2 键盘快捷键（后续版本）

| 快捷键 | 功能 |
|:--:|------|
| `E` | 结束回合（End Turn） |
| `1~0` | 快速选取手牌第1~10张（选取后仍需鼠标点目标） |
| `Esc` | 打开暂停菜单 |

> MVP 阶段键盘快捷键非必需，但结束回合的 `E` 键建议预留。

## 3. 分辨率基准

| 项目 | 值 |
|------|------|
| **设计基准** | 1920 × 1080 (Full HD) |
| **最小支持** | 1280 × 720 |
| **缩放策略** | Canvas Scale 自适应（保持宽高比，留黑边） |
| **目标平台** | PC 优先 → 后续适配移动端 |

### 3.1 显示设置与分辨率状态

设置中的分辨率选项是实际显示设置，不是仅修改下拉框文案。当前 MVP 只正式支持 `1920×1080`、`1600×900`、`1280×720` 三档 16:9 分辨率；其他尺寸必须隐藏、禁用或明确提示“当前版本不支持”，不得显示已选择但窗口/viewport 未变化的假成功状态。

| 操作/状态 | UI 行为 | 验收要求 |
|-----------|---------|----------|
| 选择受支持分辨率 | 立即通过统一显示设置服务应用窗口与 viewport；成功后保存为用户设置 | 实际窗口/viewport 尺寸变为所选值，设置页重开时仍选中当前实际值 |
| 应用失败 | 下拉框恢复到上一次实际生效值，并显示可读错误 | 不保留“已选择”假状态，不出现无反馈的失败 |
| 取消/关闭设置 | 只关闭设置 UI；已成功应用的分辨率不回滚 | 回到原节点页，当前显示尺寸保持；重开设置显示实际尺寸 |
| 切场景/重启 | 读取已保存的最后成功设置 | 场景切换不重置尺寸；重启后恢复最后成功值，读取失败时显式回退到推荐值并提示 |
| 低分辨率限制 | 小于 `1280×720` 或非受支持比例 | 禁用/提示，不压缩到文字重叠、按钮不可点或胜利面板被裁切 |

│  标题    │────▶│ 角色选择  │────▶│ 底页=道韵选择      │────▶│  左右立绘     │
└──────────┘     └──────────┘     │ 呼出=MapOverlay(toggle)│   │  点击出牌     │
                                  └──────────┬────────┘     └───────┬──────┘
                                             │                      │
                                             │    战斗胜利           │
                                             │    ┌────▼─────────┐   │
                                             │    │ 胜利弹窗      │   │
                                             │    │ · 灵韵 +12    │   │
                                             │    │ · 卡牌奖励入口  │   │
                                             │    │ · 地图（外置） │   │
                                             │    └──────┬───────┘   │
                                             │           │            │
                                             │    ┌──────▼───────┐   │
                                             │    │ CardReward   │   │
                                             │    │ overlay 3选1  │   │
                                             │    └──────┬───────┘   │
                                             │           │            │
                                             ◀───────────┴────────────┘

> Act 1 采用节点页面底层 + 地图/套牌呼出层的统一壳层。场景B 仍负责道痕固化和地图进入；战斗、灵脉、商店、问号事件和 Boss 均进入各自节点页面，不把节点内容塞回地图底页。

### 4.1 Act1 NodePage 统一壳层

第一大关的战斗、灵脉、商店、问号事件和 Boss 都是独立节点页面。节点页面只负责当前节点的内容；当前/最大生命、基础最大灵力、永久套牌、灵韵、道痕/法宝和地图进度属于 RunState，由统一 TopBar/overlay 读取，不因页面切换重置。当前回合灵力、护体、斗劲和战斗临时状态属于 BattleState，只在 BattleNode 内使用。

```
NodePageRoot（当前节点页面，底层）
  ├── NodeContent（Battle / Lingmai / Shop / Event / Boss）
  ├── TopBar（固定，读取 RunState）
  ├── NodeMapEntry（节点页外置地图入口；不属于 NodeContent 主面板）
  ├── MapOverlay（呼出式；交互性由 NodeContext 决定）
  ├── DeckOverlay（呼出式，只读查看当前牌组）
  └── SettingsOverlay（呼出式模态层，最高层）
```

统一输入优先级从上到下为：Transition/Error → 全局操作层（TopBar + NodeMapEntry）→ 当前 Map/Deck/Settings overlay → NodeContent。全局操作层只保留其字面入口行为，不能把点击穿透给下层；overlay 关闭后焦点回到打开它的按钮或当前节点，不把点击穿透到底层。

MapOverlay 是当前节点页上的共享地图视口，不是独立导航页或右侧抽屉。左边界固定，通过 Clip/Mask 从左向右揭示；内容宽度由 `MapGraph` 计算。打开后支持横向滚轮和左键拖拽，位置必须 clamp 在内容边界内；拖拽超过阈值不触发节点点击。战斗进行中地图只读；Battle 胜利结果、LingmaiNode 与 ShopNode 的 TopBar/NodeMapEntry 打开同一张可交互地图，玩家可点击合法下一节点离场。Event/Boss 的交互性由 `NodeContext` 明示，UI 不以“是否已结算”猜测。

| 层级 | UI 层 | 默认输入 | 打开/关闭规则 |
|------|------|----------|---------------|
| 0~49 | 节点底层页面 | 接收当前节点操作 | 进入节点创建，退出节点销毁；不持有跨节点进度 |
| 50~79 | TopBar | 可点击套牌、地图、设置 | 节点页面始终可见；节点结算/场景切换时暂时禁用 |
| 全局操作层（集中常量） | NodeMapEntry | 与 TopBar 地图按钮同一 toggle 命令；仅打开/收起当前页 MapOverlay | 位于 NodeContent 主面板外的右侧偏下固定锚点；不得被内容遮罩、胜利/奖励遮罩或 CardReward 误伤；仅 Transition/Error 可阻断；不新增或改写既有数值区间 |
| 100~199 | MapOverlay | 共享地图视口打开时独占内容区输入 | TopBar/NodeMapEntry 均可 toggle；固定左侧揭示；再点入口、收卷按钮或返回键关闭；MapScene、Battle 胜利、Lingmai、Shop 按 NodeContext 可操作，战斗中只读 |
| 200~299 | DeckOverlay | 只读查看套牌 | TopBar 套牌按钮 toggle；再点按钮、关闭按钮或返回键关闭；不得叠开多个套牌页面，不改变牌组 |
| 300~399 | SettingsOverlay | 模态独占输入 | TopBar 设置按钮打开；关闭按钮或返回键关闭；不得覆盖或重置节点状态 |
| 400~449 | VictoryModal | 胜利总面板的遮罩与结果页 | 进入胜利后创建；遮罩只拦截 TopBar 下缘以下的内容区输入，TopBar 全局入口保持可操作 |
| 450~469 | VictoryMapOverlay | 从胜利页主面板外 `NodeMapEntry` 或 TopBar 地图入口呼出的地图 | 关闭后精确回到原胜利/奖励焦点；仅合法下一节点点击才离场 |
| 470~489 | CardRewardOverlay | 胜利总面板上方的卡牌奖励 | 跳过/关闭只关闭自身，恢复胜利总面板焦点和原奖励进度 |
| 490~499 | Transition/Error | 阻断所有输入，直到完成或返回 | 只用于切换、错误和明确结果提示 |

约束：地图、套牌、设置三类 overlay 由一个统一 overlay 协调器管理，同一时间最多一个处于打开态。打开新 overlay 时关闭旧 overlay 并恢复其输入状态；不能通过重复点击产生多个副本。节点页面不得直接创建第二套 TopBar、地图或套牌查看器。

#### NodeMapEntry：统一外置地图入口

`NodeMapEntry` 是胜利、灵脉、商店等节点页共用的外置操作位，不是节点结算按钮。1920×1080 基准使用视口右下锚点：`right=64px`、`bottom=72px`、`width=200px`、`height=64px`；1280×720 等比缩放后按钮不得小于约 `133×43px`。它必须位于主内容面板外，和 TopBar、主面板、卡牌奖励候选区均不重叠。

- 固定文案为 `地图`，配合地图图标；关闭态 tooltip 为“打开地图卷轴”，打开态 tooltip 为“收起地图卷轴”。不得使用“继续”“返回地图”“放弃灵脉”“离开”或“完成商店结算”等会暗示结算、离场或放弃的文案。
- 点击只发出与 TopBar 地图按钮完全相同的 `ToggleOverlay(MapOverlay)` 命令：不领取奖励、不提交/消费节点、不结算灵脉或商店、不改变 RunState/NodeResult、不离开当前页面。
- MapOverlay 关闭后，原节点页、主面板、已选奖励/选项和滚动位置必须精确恢复；真正离场只由地图内点击合法下一节点触发。
- `NodeMapEntry` 只有在地图 overlay 动画中、Transition/Error、缺失有效地图上下文时禁用；不得因未领取战利品、未选择灵脉、未购买商品、选项已灰置而禁用。不可用时保留位置并显示原因，不能消失造成布局跳动。
- 实现使用集中层级常量表达“高于全部内容区遮罩、低于 Transition/Error”的相对顺序；不得因当前临时 ZIndex 数值而修改既有冻结区间或散落硬编码数值。

#### TopBar 连续横条

TopBar 背景横条在每个 NodePage 都必须从视口左边缘连续延伸到右边缘，包括右侧菜单按钮背后的留白区。1920×1080 基准高度 `44px`，根背景使用全宽锚点（`left=0`、`right=0`），右侧套牌/地图/设置组以 `right=24px`、按钮间距 `8px` 布局；任何容器裁切、透明占位或按钮组宽度计算不得在菜单区域前后留下断裂/空洞。1280×720 等比缩放时横条和菜单背景仍连续，按钮热区不小于约 `40×40px`。

### 4.1.1 胜利模态焦点

胜利奖励总面板是 BattleNode 内容区的独占 modal，不是普通漂浮卡片。`VictoryModal` 必须包含从 TopBar 下缘开始的内容区输入阻断根节点、背景降暗层、胜利总面板和上层入口；不能依赖逐个禁用手牌、结束回合、日志或 Debug 按钮来模拟模态。TopBar 是全局常驻入口，不属于该模态遮罩范围。

- 背景降暗层使用墨黑/深褐遮罩，推荐 alpha `0.72`，允许范围 `0.68~0.78`。战斗场景仍隐约可辨，但不应与面板正文争夺注意力；胜利面板自身背景 alpha 不低于 `0.96`，正文和主要按钮保持可读。
- 胜利 modal 出现至关闭期间，手牌、敌我立绘交互、日志、结束回合、F9 手牌调试入口及所有 Debug 控件都不可接收 hover、点击、拖拽或快捷操作；下层即使视觉上露出也不得有任何状态变化。TopBar 的地图、套牌、设置入口始终可点击。
- `CardRewardOverlay` 位于总面板之上，但同样只独占内容区。关闭或跳过只移除 CardReward 自身，随后立即恢复同一胜利总面板的焦点、奖励行、候选顺序和已选进度；不得恢复下层战斗输入，也不得改变 TopBar 可用性。
- 胜利页 `NodeMapEntry` 与 TopBar 地图入口都可打开 `VictoryMapOverlay`；TopBar 套牌/设置也可在胜利或 CardReward 焦点上打开对应 overlay。任一全局入口 overlay 关闭后，必须精确恢复其打开前的胜利/奖励焦点与进度；只有地图内点击合法下一节点才离开 BattleNode。
- 胜利页主面板内不放置“继续”按钮；使用上述 `NodeMapEntry`。该入口与 TopBar 地图按钮等价，且不受 VictoryScrim/CardReward 遮罩阻断。

### 4.2 跨节点状态边界

| 切换时保留的 RunState | 离开节点时丢弃的 BattleState/UI 瞬时状态 |
|------------------------|--------------------------------|
| 当前生命/生命上限、基础最大灵力（角色永久属性） | 当前回合灵力、护体、斗劲、易损/永炎等战斗临时状态 |
| 永久套牌及升级/新增结果 | 战斗抽牌堆、手牌、弃牌堆、消弭牌和敌人运行态 |
| 灵韵、道痕、法宝/道器、Act/Seed、已访问节点和地图当前位置 | 地图/套牌/设置 overlay 的打开状态和动画中间态 |
| Act/Seed/地图进度（含已访问节点、已提交奖励和完成标记） | 旧胜利弹窗、CardReward 选项、旧节点按钮和旧日志内容 |

非 BattleNode 的 TopBar 不显示当前回合灵力、护体、斗劲或敌人临时状态；BattleNode 读取 BattleState 的战斗信息，离开战斗后由 NodeResult 提交允许跨节点的结果并清理 BattleState。

节点切换必须通过场景入口契约传递上下文；新页面不能调用角色初始化、重建牌组或清空生命。若进入/退出失败，页面显示可追踪错误并返回安全入口，不静默伪造成功。

### 4.3 Act 1 节点页面验收口径

- 进入战斗、灵脉、商店、问号或 Boss 后，当前节点页面是底层主内容；地图和套牌只能通过 TopBar 呼出。
- 战斗进行中打开地图时只读；Battle 胜利、灵脉和商店页面通过 TopBar/NodeMapEntry 打开地图时，可点击合法下一节点。打开入口本身不做结算或离场；Event/Boss 是否可点击节点由 NodeContext 明示。
- 节点页面打开套牌 overlay 只读查看，不改变牌组、不重抽奖励、不重置当前页面选项。
- 打开地图/套牌时，下层节点按钮不响应点击；关闭后焦点回到原按钮或当前节点，不穿透触发底层选项。
- 节点结果、消费与访问状态只能由明确的玩法动作或地图内合法节点转换契约写入；返回、取消或 NodeMapEntry 均不伪造成功结算。灵脉、商店、问号的已访问状态必须由结果契约统一写入。
- 胜利、灵脉、商店页面的 `NodeMapEntry` 不提交 `NodeResult`；它只打开/关闭地图 overlay。未选择灵脉或未购买商店物品时，玩家可通过该入口查看并在地图中选择合法下一节点，节点进入/离场事务不由入口按钮提前执行。

## 5. 通用交互组件规范

### 5.1 按钮

| 状态 | 视觉 | 说明 |
|------|------|------|
| **默认** | 沉郁棕底 + 米白文字 | 可用状态 |
| **悬停** | 边框高亮 + 轻微放大(105%) | 鼠标移入 |
| **按下** | 下沉效果 + 颜色加深 | 点击瞬间 |
| **禁用** | 灰色 + 降低不透明度(50%) | 不可用（如灵力不足） |

### 5.2 Tooltip（悬停提示）

| 元素 | 规范 |
|------|------|
| **触发** | 鼠标悬停 0.3 秒后弹出 |
| **位置** | 跟随鼠标右上方偏移 |
| **内容** | 短信息直接展示；长信息分"简述 + 详情"两段 |
| **消失** | 鼠标移出即消失 |

### 5.3 过渡动画

| 场景 | 动画 | 时长 |
|------|------|:--:|
| 界面切换 | 淡入淡出 | 0.4s |
| 卡牌出现 | 从底部飞入 + 轻微弹跳 | 0.3s |
| 选择确认 | 选中卡牌放大 + 未选中缩小消失 | 0.3s |
| 伤害飘字 | 从目标身上浮起消失 | 0.6s |

### 5.4 确认/取消模式

- 重要选择（道痕固化）：点击后短暂高亮（0.5s），**无需二次确认**（避免打断节奏），但选择即不可逆
- 卡牌奖励：可点击"跳过"按钮跳过不拿

## 6. 字体与色彩规范

### 6.1 字体

| 用途 | 字体 | 备选 |
|------|------|------|
| 标题/角色名 | 书法体（如"汉仪柏青体"或自选毛笔字体） | 系统默认衬线字体 |
| UI文本/卡牌描述 | 清晰易读的衬线中文字体 | 系统默认 |
| 数值（伤害/HP） | 粗体数字，醒目优先 | — |
| 背景文本（卡牌底部小字） | 小号书法体，半透明 | — |

### 6.2 色调

| 色值 | 用途 |
|------|------|

## 7. 信息架构优先级

```
战斗中（从上到下）：
  Level 1（最显眼）— 敌人血量/意图、玩家血量/灵力
  Level 2（常用）   — 手牌区
  Level 3（查看）   — buff/debuff 图标、弃牌堆/牌库数量
  Level 4（辅助）   — 回合数、道痕列表、结束回合按钮
```
