## 使用规则

- 每次功能完成后，至少跑和任务相关的局部验收。
- 每次准备发布前，跑完整 MVP 主流程验收。
- 验收失败时记录复现步骤、预期结果、实际结果和相关截图/日志。
- UI 验收按玩家真实操作执行，不只检查节点是否存在；每项至少确认“入口、操作反馈、结果状态”三件事。
- 文档、代码、美术占位不一致时，按下方“差异与风险归属”记录，不在验收时口头跳过。

## MVP 最小 UI 验收路径

这条路径从玩家视角验证“启动到完成一次战斗奖励回地图”的最小闭环。执行前建议清空本次运行状态或从标题界面重新开始。

| 步骤 | 玩家操作 | 必看反馈 | 失败判定 |
|------|----------|----------|----------|
| 1 | 启动游戏 | 进入标题界面；能看到开始、时间线、设置、退出、版本号 `v0.0.1-alpha` | 无法进入标题、主按钮缺失、版本号缺失 |
| 2 | 点“开始游戏” | 进入角色选择；巫祝默认选中 | 进入错误场景、无默认角色 |
| 3 | 查看角色栏 | 巫祝有选中标记；锁定角色灰显/锁定但可见；随机按钮可见 | 锁定角色被隐藏或可直接开局 |
| 4 | 点锁定角色，再点随机 | 锁定角色有轻微反馈但不切换；随机仍选巫祝 | 锁定角色变为可用角色 |
| 5 | 点角色选择“开始游戏” | 进入 MapScene；底页直接显示 3 张道韵/道痕卡 | 进入旧道痕场景或空白页 |
| 6 | 未固化前点 TopBar“地图” | 地图卷轴从右侧呼出；战斗节点灰显/不可进入，并有“需先固化道痕”类反馈 | 未选道痕即可进战斗 |
| 7 | 收卷，固化任一张道痕 | 被选卡高亮并显示“已固化”；其余卡变灰；固化按钮消失 | 可反复固化、无选中反馈 |
| 8 | 再点“地图”，点击可达战斗节点 | 节点解锁，点击后进入 Battle | 固化后仍不可进战斗 |
| 9 | 战斗中观察布局 | 左侧巫祝、右侧山野妖猴、顶部 TopBar、底部手牌、灵力和结束回合可见 | 核心信息重叠或不可读 |
| 10 | 点击 1 张斗击牌，再点敌人区域 | 手牌呈底部牌扇：中心最高最正，左右逐步降低并轻旋；斗击卡 hover/选中时摆正放大但本体不飞出手牌栏，箭头从卡牌指出并以上凸弧线指向鼠标/目标，确认后扣费、造成伤害并立刻重排剩余手牌 | 散乱旋转、不是牌扇；hover 保留倾斜角度导致卡面不正；斗击卡飞到战场中央；箭头从玩家立绘出发、不可见或呈下凹弧线；出牌后剩余手牌留下空位 |
| 11 | 点击或拖动 1 张术法牌 | 默认自身或无目标术法不显示攻击箭头；长按拖出手牌区松手自动打出；点击选中后也应进入跟随鼠标的持牌状态，在手牌区外再次点击自动打出；需要目标的术法才进入目标选择；打出后剩余手牌立刻重新居中成扇形 | 默认自身/无目标术法仍要求点击自身立绘；点击选中后卡牌不能跟随鼠标拖出；有目标/无目标规则只能靠牌名硬判；出牌后手牌留空位 |
| 12 | 灵力不足时尝试点高费牌 | 卡牌灰暗且不能选中/打出 | 灵力不足仍可打出 |
| 13 | 点“结束回合” | 敌人按意图行动；回合切回玩家后灵力恢复并抽牌 | 回合卡死或敌人不行动 |
| 14 | 击败山野妖猴 | 就地弹出胜利弹窗；包含灵韵、卡牌奖励、继续；不显示道器碎片占位 | 直接跳走、弹窗缺项或仍显示未开放道器碎片 |
| 15 | 点“灵韵 +X” | 灵韵到账，奖励行消失或变为已领取 | 可重复领取 |
| 16 | 点“卡牌奖励（3选1）” | CardReward overlay 叠在胜利弹窗之上，胜利弹窗仍在下层 | 奖励变成独立场景或销毁胜利弹窗 |
| 17 | 打开卡牌奖励后点“跳过”，再重复打开 | 每次只关闭 CardReward overlay；胜利页奖励行仍在；候选牌 ID、顺序和已选进度完全一致；未选择时永久牌组与奖励状态不变 | 奖励行消失、候选重抽/换序、已选进度丢失、牌组或奖励状态被修改 |
| 18 | 重新打开并选择所需卡牌 | 卡牌加入牌组；达到 ChoiceCount 后 overlay 关闭，已完成奖励行才消失；不能重复领取 | 未完成选择就删除奖励行、已完成后仍可重复领取、牌组数量错误 |
| 19 | 点“继续” | 当前胜利/奖励页不销毁；地图以 overlay 从左向右展开；关闭地图后页面和奖励状态原样恢复，可再次打开 | 切换到 MapScene、清空胜利页、出现 TopBar + 空白底页、关闭后无法恢复 |
| 20 | 在地图上滚轮或按住左键拖动 | 可横向查看后续层节点；位置受边界限制；拖拽不误触节点，点击仍能正常选节点 | 后续节点不可见、地图越界、拖拽触发节点、只能通过右侧抽屉查看 |
| 21 | 点击可达灵脉/商店/事件节点 | 只有点击合法节点时才离开当前页并进入目标节点页面 | 打开/关闭地图就离场、进入无关或空白页面 |
| 22 | 在灵脉/商店/事件页点击外置“🗺 地图”或 TopBar“地图” | 当前节点页保留；地图作为 overlay 打开；关闭后回到同一页面。地图入口不得结算、离场或消费任何选项/奖励 | 清空节点内容、切换空白 MapScene、重复执行节点效果、点击入口产生 NodeResult |
| 23 | 点击可达灵脉节点 | 打开灵脉选项界面；不出现“返回地图/放弃灵脉”；外置“🗺 地图”持续可用 | 点击无反应、只关闭地图层或重新露出旧奖励界面 |
| 24 | 灵脉不选行动，点击外置“🗺 地图” | 当前位置已推进至灵脉，地图立即显示并允许点击下一层合法节点；灵脉选项不被消耗 | 仍停留在进入灵脉前的位置、下一节点不可选、灵脉被提前消耗 |
| 25 | 选择任一灵脉选项后再开图/关图 | 仅该选项灰置，其他选项和当前页面状态保持；关闭地图后可回到灵脉页 | 多个选项被连带灰置、开图导致结算或离场、重复执行节点效果 |
| 26 | 战后打开 CardReward，再点击右下“🗺 地图” | 奖励 overlay 可恢复关闭并打开地图；除 NodeMapEntry 与 TopBar 外，内容区仍不可输入；关图后同一候选与多选进度恢复 | 地图入口被奖励层挡住、手牌/日志等穿透、候选重抽或进度丢失 |
