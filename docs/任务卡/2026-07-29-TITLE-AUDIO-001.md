# TITLE-AUDIO-001 标题页 BGM 接入

## 背景

用户已提供并批准以下文件作为标题页 BGM：

- 用户批准源：`D:\用户目录\Music\afterhh\出发-on-the-way.wav`
- 文件大小：31,350,156 bytes
- SHA-256：`41D41C78F8D15A26199A808278D39E5666540D217979DAB0D8707CEF82501C5B`
- 参数：PCM 16-bit、44.1 kHz、立体声、约 2:57.72
- 技术检查：完整解码通过；平均音量约 -15.6 dB，峰值约 -0.9 dB；开头约 0.64 秒静音

标题视频已替换为无音轨运行时资源，因此本任务只接入独立 BGM，不再修改视频。

## 目标行为与验收标准

1. 将用户批准 WAV 保存为唯一正式音乐母版。
2. 生成 Godot 支持的 OGG Vorbis 运行时音乐，保留 44.1 kHz 立体声和完整约 2:57.72 时长，不裁剪、不变速、不重混。
3. 标题场景内只有一个局部 `AudioStreamPlayer`，使用场景资源引用、`autoplay=true`、默认 `Master` bus、初始 `volume_db=-6.0`。
4. BGM 使用音频流自身的显式循环能力，从曲目开头独立循环，不与 16.21 秒标题视频同步。
5. 离开标题场景后播放器随场景销毁停止；重新进入标题场景时从头播放，不引入全局持久播放器或重复实例。
6. BGM 不拦截输入，不改变标题视频、开始游戏、设置、退出或场景跳转行为。

## 升级条件

遇到以下情况立即停止并向总项目经理报告：

- 用户批准源无法完整解码或哈希不一致。
- Godot 无法可靠导入或循环 OGG。
- 必须修改 C#、添加全局服务或改变标题流程才能接入。
- 发现目标场景或音频路径包含无法区分的其他未提交修改，继续会覆盖非本任务工作。
- 工具无法使用 `gpt-5.6-luna`、`max` 执行部门任务。
