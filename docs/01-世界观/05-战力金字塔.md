# 05-战力金字塔

> 版本: 0.4.0 | 状态: ✅ 已完成 | 来源: 游戏设定文档 第5章

---

这是洪荒世界通行的修为境界体系。游戏中玩家从 **地仙** 起步，最终可能触及 **大罗** 边缘。

| 层级 | 境界 | 特征 | 对应游戏中的 |
|:--:|------|------|------|
| **-1** | **凡人** | 普通生灵，未入仙道 | — |
| **0** | **地仙** | 镇守山川地脉，肉身超凡，寿元千元会 | 玩家起始/小怪 |
| **1** | **天仙** | 位列仙班，可使用小神通，短暂飞行 | 普通小怪 |
| **2** | **真仙** | 元神不灭，自我成道 | — |
| **3** | **玄仙** | 丹田化宇宙，明悟天地法则真义 | 第二层普通敌人 |
| **4** | **金仙** | 执掌大道法则，一丝真灵可重生，**跳出寿命限制** | 第二层精英 |
| **5** | **太乙金仙** | 法则入道，多条法则圆满 | 第二层Boss / 第三层敌人 |
| **6** | **大罗金仙** | 超脱时间长河，过去现在未来三身合一，元神不朽 | 第三层精英 / Boss |
| **7** | **准圣（混元金仙）** | 走上成圣之道，斩尸/法则融合 | 鲲鹏残魂、冥河老祖级别 |
| **8** | **圣人（混元大罗金仙）** | 天道圣人，掌天道法则，不死不灭。立教可证道 | 六圣——不可挑战 |
| **9** | **天道级** | 鸿钧——身合天道，制衡诸圣 | — |

## 巫族特殊体系

巫族不修元神，没有传统境界，但战力等价：

| 巫族称号 | 等同修为 | 代表 |
|------|:--:|------|
| **祖巫** | 准圣巅峰（肉身无敌） | 帝江、祝融、共工等 |
| **大巫** | 大罗金仙至准圣初级 | 蚩尤、刑天、九凤、后羿 |
| **祭巫/真巫** | 金仙至太乙金仙 | 部落的中层战力 |
| **巫人/巫民** | 地仙以下 | 普通巫族子民 |
