## 四大部洲

巫妖量劫后，洪荒大陆崩碎。六圣合力将碎片重组为四大部洲：

| 洲名 | 特征 |
|------|------|
| **东胜神洲** | 灵气充沛，仙道昌盛。八景宫、玉虚宫、十二金仙洞府所在 |
| **南赡部洲** | 人族主要栖息地，三皇五帝将兴。九黎部落（蚩尤）、常羊山（刑天）所在 |
| **西牛贺洲** | 灵脉被毁，西方教将兴起。灵山、方寸山、五庄观在此 |
| **北俱芦洲** | 苦寒之地，妖族退守的最后的避难所。鲲鹏妖师宫在北冥（北海之极） |

四海环绕四大部洲，由龙族永镇四海龙宫。海外十三岛散落四海之中，为各方散修的隐秘洞府。

天界重组为三十三重天，昊天上帝+瑶池金母主持天庭。混沌天外有紫霄宫（鸿钧）、娲皇宫（女娲）。幽冥地下有血海（冥河·阿修罗族）、六道轮回（后土/平心娘娘）。

## 遗荒：世界中央的禁区

四大部洲中间不是海——原本是连接四洲的中央大陆。巫妖大战的核心区域就在这里。战后它被命名为**遗荒**，一个无主、无人管、也无人定居的禁区：

| 特征 | 说明 |
|------|------|
| **定位** | 洪荒大陆原本的中心，被四大部洲环绕 |
| **现状** | 天地灵气极度紊乱，法力不稳定 |
| **危险** | 空间碎片残留（帝江法则破裂）、祖巫煞气弥漫 |
| **归属** | 无主之地——没有任何教派在此立教，六圣补天后也未收复 |
| **生物** | 只有最外围有不周山溅射碎片形成的边缘生态区（低阶妖物、散修猎人） |

> 不是进不去——圣人当然进得去。但修仙是讲性价比的，没人在废墟里建道观。

遗荒内部呈同心圆自然分层：

| 圈层 | 战后成因 | 生物状态 |
|------|------|------|
| **外圈·不周废墟** | 不周山倒塌溅射的最外层碎片、天河残水 | 山精野怪、散修猎人可存活 |
| **中圈·太阳残宫** | 天庭坠落区，帝俊太一自爆冲击波 | 只有火元素生命体和失控傀儡 |
| **内圈·都天神渊** | 祖巫之血浸透中心，帝江空间裂缝 | 没有任何自然生命——只有煞气化形和残念 |
| **核心·虚空茧** | 帝江爆炸点，空间法则扭曲 | 第十三人正在其中诞生 |
