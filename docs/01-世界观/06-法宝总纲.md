## 法宝等级体系

本文档描述洪荒世界观层面的法宝分类。游戏内遗物设计见 [03-玩法系统/04-法宝系统(游戏内).md](../03-玩法系统/04-法宝系统(游戏内).md)。

法宝按来源和品阶分为六等，从高到低：

```
混沌至宝（已不存在，开盘古开天均碎裂）
    ↓ 碎裂后降级为
先天至宝（至高，洪荒最强法宝）
    ↓
先天灵宝（天地自然孕育）
    ├── 极品先天灵宝
    ├── 上品先天灵宝
    ├── 中品先天灵宝
    └── 下品先天灵宝
    ↓
后天灵宝（人为炼制或天地生成但非先天）
    ├── 后天功德至宝（威力可达先天至宝级别）
    ├── 后天至宝
    └── 后天灵宝（普通）
```

| 等级 | 说明 | 示例 |
|------|------|------|
| **混沌至宝** | 开天辟地前已存在，盘古开天后碎裂殆尽 | 开天斧（裂为太极图+盘古幡+混沌钟） |
| **先天至宝** | 混沌至宝裂变或天地初生时孕育 | 东皇钟（混沌钟）、盘古幡、太极图 |
| **极品先天灵宝** | 先天灵宝中顶尖者，威力接近至宝 | 诛仙四剑、河图洛书、十二品功德金莲 |
| **上品先天灵宝** | 先天灵宝中上等 | 山河社稷图、五色神光 |
| **中品先天灵宝** | 常见先天灵宝 | 大部分洞府法宝 |
| **下品先天灵宝** | 低阶先天灵宝 | — |
| **后天功德至宝** | 以功德淬炼的后天法宝，战力等同于先天至宝级 | 玄黄玲珑塔 |
| **后天至宝** | 以顶级材料+圣人手段炼制 | 翻天印（半截不周山所炼） |
| **后天灵宝** | 普通修士炼制 | 修士个人法器 |
