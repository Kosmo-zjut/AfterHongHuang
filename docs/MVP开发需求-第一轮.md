# MVP 第一轮开发需求 — 核心玩法验证

> 发起方：策划部 | 版本：2.1 | 日期：2026-07-07
>
> 目标：用最少代码跑通 `标题界面 → 角色选择 → MapScene（底页道韵3选1 + 呼出地图卷轴）→ 战斗 → 胜利弹窗 → 卡牌奖励 overlay → 回地图` 的完整闭环。

## 闭环流程

```
场景0：标题界面
  → 场景A：角色选择
  → 场景B：MapScene
      ├── 底页：3张道韵卡（直接渲染，非 overlay）
      │     → 点「固化」→ 选中高亮+✓ 标记，其余变灰
      └── 呼出：地图卷轴（TopBar 地图按钮 toggle，右→左展开）
            → 选完道韵 → 节点解锁 → 点击进入战斗
  → 场景C：战斗（左右立绘 + 底部手牌 + 点击选中出牌）
      → 战斗胜利 → 就地弹出胜利弹窗（灵韵/道器占位/卡牌奖励入口/继续）
          → 卡牌奖励：CardRewardHelper overlay 叠在胜利弹窗上（3选1）
          → 回 MapScene（继续探索）
```

## 场景0：标题界面

### 界面要素

- 全屏大插画背景（水墨厚涂，洪荒废墟场景。MVP可用单张静态占位图）
- 四个按钮自上而下排列：
  - **开始游戏**（主按钮，最醒目）
  - **时间线**（剧情模块，MVP可点但弹"开发中"提示）
  - **设置**（MVP可点但弹"开发中"提示）
  - **退出游戏**（必须可用）
- 右下角版本号 `v0.0.1-alpha`

### 交互

- 点击"开始游戏"→ 场景淡出 → 进入角色选择
- 点击"退出游戏"→ 退出程序
- 时间线/设置：MVP阶段弹提示"修炼中，暂未开放"

## 场景A：角色选择

### 界面要素

- **全屏背景**：当前选中角色的个人插画（每个角色一张专属图）
  - 切换角色时背景交叉淡入淡出（0.4s）
- **右侧信息面板**（半透明悬浮底板）：
  - 角色名称（大字书法体）
  - 角色简介（2~3行）
  - 初始牌组预览（拳袭×4 格挡×4 烈拳×1 燃血×1）
  - 生命上限（80）
  - "开始游戏 >>" 按钮
- **底部角色栏**（水平并排 6 个头像框）：
  - 巫祝（已解锁·默认选中：金色边框 + ✓）
  - 盗宝者（锁定·灰度 + 🔒）
  - 截教门徒（锁定·灰度 + 🔒）
  - 金乌遗孤（锁定·灰度 + 🔒）
  - 凡人（锁定·灰度 + 🔒）
  - 随机按钮（骰子/问号图标，始终可点击；MVP仅巫祝可用=随机必选巫祝）

### 交互

- 默认选中巫祝
- 点击锁定的角色 → 无反应（可轻微抖动提示）
- 悬停锁定角色 → tooltip"此角色将在后续版本中开放"
- 点击"开始游戏"→ 进入道痕选择界面

### 初始化数据（巫祝）

```
生命上限：80
当前生命：80
灵力：3/3（每回合）
初始牌组（10张）：
    拳袭  ×4  斗击 / 1费 / 造成6伤害
    格挡  ×4  术法 / 1费 / 获得5护体
    烈拳  ×1  斗击 / 2费 / 造成8伤害 + 施加2层易损
    燃血  ×1  术法 / 1费 / 失去2HP + 获得1点斗劲
```

## 场景B：道痕选择 + 地图切换

### 核心交互

这是一个**双面板界面**：
- 默认显示道痕选择（3张道痕卡横排并排）
- 右上角有"🗺 地图"按钮，点击切换到地图路线视图
- 地图视图右上角有"✦ 道痕"按钮，点击切回道痕选择
- **两个面板来回切换不受限制**，但在选完道痕之前，地图上所有战斗节点 🔒 锁定
- **必须先选道痕，才能点击地图节点进入战斗**

### 界面要素（道痕模式）

- 右上角"🗺 地图"切换按钮
- 标题"道韵浮现，择一而固"
- 3张道痕卡片居中横排，悬停放大110%
- 点击一张即固化（不可撤销，无二次确认弹窗）

### 界面要素（地图模式）

- 右上角"✦ 道痕"切换按钮（按钮上红色小圆点提示"未选择道痕"）
- 关名标题"不周废墟 · 外围"
- 玩家节点（当前位置）+ 下方战斗节点（🔒锁定，悬停显示"需先固化道痕"）
- 道痕选完后所有节点锁解除 → 点击第一个节点进入战斗

### 数据

从下品道痕池随机抽3条，池内容：

| 道痕名 | 效果 |
|------|------|
| 九乌坠日 | 每场战斗开始时，给所有敌人 3层永炎 |
| 飞廉失风 | [占位：暂无效果，可跳过] |
| 九婴水火 | [占位] |
| 呲铁锻金 | [占位] |
| 商羊预兆 | [占位] |
| 符修遗箓 | 击败敌人后额外获得一次卡牌奖励 |
| 体修金刚 | 最大生命值 +10 |
| 阵修困天 | [占位] |
| 蛟龙蜕鳞 | [占位] |
| 灵凤离火 | [占位] |
| 星辰幡残念 | [占位] |
| 都天神煞 | [占位] |

> MVP阶段，占位道痕可在抽选时从池中剔除，仅用3条有实际效果的（九乌坠日/符修遗箓/体修金刚）即可。如果3条正好都在池中就直接用这3条；如果将来池子扩充到>=3条有效果的，按随机3选1逻辑。

## 场景C：战斗

### 界面要素

- 玩家手牌区（底部）
- 玩家状态栏：HP / 护体 / 灵力 / 斗劲层数 / debuff 图标
- 敌人区域：山野妖猴 ×1
- 敌人状态栏：HP / 护体 / 意图图标 / buff/debuff 图标
- 回合结束按钮

### 回合流程

```
玩家回合开始
    ├── 抽满5张手牌（若牌库不足则将弃牌堆洗回牌库）
    └── 灵力回满至当前上限（初始3）
    ↓
玩家回合（自由出牌）
    ├── 点击手牌 → 扣费 → 执行效果
    ├── 已打出的牌进入弃牌堆
    └── 点击"结束回合" → 进入结算
    ↓
玩家回合结束结算
    ├── 护体清除
    ├── 玩家身上的永炎/灼烧/毒素扣血
    └── 手中未打的牌保留（非弃牌）[需确认：尖塔是弃掉，MVP可简化]
    ↓
敌人回合开始
    ├── 妖猴按意图执行动作
    └── 显示伤害数字/效果
    ↓
敌人回合结束结算
    ├── 敌人护体清除
    └── 敌人永炎/灼烧/毒素扣血
    ↓
玩家回合开始（循环）
```

### 伤害公式

```
实际伤害 = floor((卡牌面板伤害 + 斗劲层数) × 易损修正 × 虚弱修正)
易损：×1.5 | 虚弱：×0.75
```

### 状态效果（MVP只用到的）

| 术语 | 效果 | 持续规则 |
|------|------|------|
| 护体 | 本回合抵挡等量伤害 | 回合结束清零 |
| 易损 | 受到的攻击伤害 ×1.5 | 持续N个目标回合，每回合结束 -1层 |
| 斗劲 | 斗击牌伤害 +1/层 | 整局有效 |
| 永炎 | 回合结束扣 X HP（X=层数） | 不衰减，不自动消除 |

### 敌人数据：山野妖猴

```
HP：60
阵营：妖
意图：
    第1回合  嬉斗（强化）— 获得 buff"灵猴闪避"
    第2回合  打7
    第3回合  打13
    第4+回合 打7/打13 交替

灵猴闪避 buff：
    - 受击计数器 = 0
    - 每被斗击牌命中一次，计数器 +1
    - 计数器 = 3 时，该次斗击伤害降为 0，计数器重置为 0
    - 术法牌不受闪避影响
    - 护体格挡不算"命中"
```

### 击败后

```
胜利提示 → 进入卡牌奖励场景
灵韵奖励：10~15（MVP阶段可只显示数字，不接入经济系统）
```

- 3张卡牌居中展示
- 玩家选一张 → 加入牌组
- "跳过"按钮（可选）

MVP 阶段使用巫祝正式最小奖赏卡池，详见 [01-卡牌系统](./03-玩法系统/01-卡牌系统.md) §10。

## 不需要做的（非 MVP）

- 不需要牌库洗牌动画
- 不需要猴子闪避的视觉特效
- 不需要灵韵经济系统接通行脚宝商
- 不需要灵脉节点（火堆/升级）
- 不需要道痕升级版卡面
- 不需要劫数（诅咒卡）
- 不需要事件/宝箱/商店
- 不需要时间线/设置的实际功能（按钮可放，点击弹"开发中"即可）
- 不需要4个锁定角色的插画（可用巫祝插画占位或纯灰背景）
- 不需要地图路线的多分支（MVP只画一条直线路径，3个节点即可）
