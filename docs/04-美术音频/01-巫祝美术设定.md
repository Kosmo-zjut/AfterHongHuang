# 01-巫祝美术设定

> 版本: 1.0.0 | 状态: ✅ 已完成 | 最后更新: 2026-07-05

---

## 角色定位关键词

**废墟中的活火焰** —— 不是漂亮的、神圣的火焰。是祝融死后最后一簇不肯灭的火。她整个人看起来像一件没烧完的东西。

---

## 基本信息

| 维度 | 设定 |
|------|------|
| **性别** | 女 |
| **年龄感** | 18-22岁。独自活太久但还没变成大人。脸上没有少女的稚气，也没有成年人的世故——是一种"被留在原地太久"的沉 |
| **身高** | 中等偏高（约170cm），骨架偏大——巫族血脉的遗留 |
| **体型** | 体脂极低，不是健美的"壮"，是"吃得不好但扛得住"的韧。肩背线条硬朗，手臂内侧和肋下有旧伤的浅色纹路——不是战斗留下的，是小时候一个人在山里摔的 |

---

## 面部与表情

| 维度 | 设定 |
|------|------|
| **脸型** | 略方的鹅蛋脸，下颌线条清晰但不锋利。颧骨不高，五官分布偏开——看起来不像"精致的美人"，更像"还没长开但已经不会长开了" |
| **眼型** | 杏眼微挑，双眼皮很浅。睫毛不长。平时眼神很沉，不怎么看人——不是害羞，是习惯了一个人待着 |
| **眼瞳** | 暗金色底。愤怒/战斗时瞳孔里会燃起针尖大的橙红火焰。情绪平静时只是暗金色，像熄灭的炭 |
| **眉** | 野生眉，不修。眉尾微微下压——看起来总像在想事情 |
| **唇** | 偏薄，颜色浅。经常抿着。不笑的时候看起来有点凶，但实际上只是没学会怎么放松 |
| **表情基调** | 静态时是一种"安静的警觉"——像野生动物在听远处的动静。笑起来应该很好看，但她几乎不笑 |

## 发型

| 维度 | 设定 |
|------|------|
| **长度** | 长发及腰 |
| **颜色** | 深黑，但在阳光下泛暗红——不是染的，是祝融血脉在毛发里的微弱显性 |
| **造型** | 粗麻绳随意束成高马尾，碎发从两侧垂下来遮住半边脸。松散、不精致——是自己绑的，没人教过她怎么梳头 |
| **特殊特征** | 发尾有不规则的烧焦痕迹，边缘是暗红色的余烬状。剪掉会重新焦——从出生就这样。看了就知道这个人跟火有关系 |

---

## 肤色与血脉印记

| 维度 | 设定 |
|------|------|
| **肤色** | 微微偏小麦色。不是日晒的均匀色泽——在终年没有阳光的废墟中长大，肤色来自体内火焰的透光 |
| **血脉印记** | 手背、锁骨、后颈有若隐若现的暗红色裂纹——不是伤疤，是祝融血脉在皮下的纹路。平时很淡，像褪色的纹身；情绪波动时会微微发橙光；战斗时整条纹路亮起来，像熔岩流过地下裂缝 |
| **特殊时刻** | 眼角在极度愤怒时会溢出一点点橙光——不是眼泪，是火焰从泪腺渗出来了 |

## 着装（分层描述，由内到外）

### 内层

贴身的深灰色布质裹胸和短裤。用的是废墟里能找到的最耐磨的料子——早就洗褪色了，边缘有自己缝补的针脚。不美观，但实用。

### 中层（皮甲）

自己拼凑的皮甲——不是锻造的铠甲，是废墟里捡来的妖兽皮、碎骨片、铁片，用皮绳绑在一起。护住胸口、肩膀和小臂。每一块材料都是自己捡的，拼得很认真但看起来还是破破烂烂。

### 外层（九凤的旧披风）

深褐色的兽皮披风，边缘磨损严重。是九凤留下的唯一遗物——对九凤来说只是件挡风的斗篷，对她来说是唯一能证明自己不是凭空出现在这个世界上的人。披风太大——不是她的尺寸，但她从来没想过改。

### 配饰

- 腰带：粗皮绳，挂了几个自己缝的小布袋——装灵石和废墟里捡来的东西
- 脚：兽皮裹腿+草鞋。脚踝有几道暗红裂纹
- 无首饰，无装饰物——不需要，也没人给

---

## 武器：烬骨甲/骨枪

### 休眠形态

平时以暗红色火焰纹身的形式蛰伏在**右臂（从手背到肩膀）**和**前胸（锁骨到胸骨）**。不是纹身——是祝融火种的寄宿形态。

纹路看起来像烧焦的树枝脉络：从心脏位置向外蔓延，右臂最密集，左手没有。静止时是暗红色的，像冷却的岩浆纹路。当她心跳加速或情绪波动时，纹路会微微泛光。

### 战斗激活

火焰纹身从皮肤上"剥离"——不是血淋淋的撕扯，更像灰烬被风吹起：
- **骨枪**从右臂纹路中抽出，在手中凝实。材质不是金属——是烧焦的白骨质感，枪身有不规则的裂纹，裂缝里透暗红色的光。枪尖是碎骨状的尖锥，没有金属光泽，只有余烬的暗红
- **烬骨甲片**同时覆盖左前臂和右手背——半透明的暗红色骨板，能看到板下火焰在缓慢流动
- 胸口纹路不剥离——那是火种的核心，一直留在皮肤下发光

### 视觉要点

| 要点 | 说明 |
|------|------|
| **材质对比** | 骨枪（硬/白/死）+ 火焰（软/红/生）——祝融死后的骨头上还在烧火，这个概念本身就很"巫祝" |
| **大小** | 骨枪比她的身高稍短，略比标准长枪粗——不是轻巧的刺枪，是可以抡起来砸的。符合体术斗击定位 |
| **攻击特效** | 挥动时枪身拖出暗红色的余烬尾迹，撞击时溅出火星而非火花——是"烧完之后的火星"，不是"正在燃烧的火焰" |

## 画风关键词（给美术的参考方向）

- **风格**：水墨厚涂，毛笔笔触感保留在轮廓线和阴影里
- **线条**：不追求工整流畅——可以有"毛边"和断线，增加粗糙感和废墟感
- **上色**：大面积沉郁色块（褐/灰/暗红），只在关键位置加高饱和点缀（火焰橙、暗金）
- **光影**：她的光源来自体内——不是环境光照亮的，是皮肤下的火在透光。所以在暗环境中，她的锁骨和手背应该有微弱的橙色透光
- **不要做的**：
  - 不要大面积火焰特效包裹身体——火种在体内，不是在外面
  - 不要性感化——她的着装是生存导向的，不是展示的
  - 不要日系萌系——她不好看，但看起来"对了"

## 参考意向

| 方向 | 参考 |
|------|------|
| **线条/笔触感** | 《雾山五行》的角色线条——粗犷、有力、毛笔质感 |
| **色调/废墟感** | 《鬼谷八荒》的暗沉色调 + 《黑暗之魂》的"熄灭后的世界"质感 |
| **火的表现** | 不是烈焰，是余烬；不是燃烧，是烧完之后还在发亮的那种 |

## 战斗中的视觉变化

| 状态 | 表现 |
|------|------|
| **待机** | 骨枪斜持，枪尾点地。血脉纹路微微发光。呼吸很慢 |
| **受伤** | 暗红裂纹短暂变亮，然后暗下去——每挨一次打，火种就弱一点 |
| **自伤（燃血类卡牌）** | 她抓住自己的右臂，纹路爆亮——是自己逼出来的。脸会皱一下，然后眼神更狠 |
| **低血量** | 纹路亮度不稳定地闪烁。骨枪上的余烬变暗。脚步开始拖。但眼神从"沉"变成"什么都不在乎了" |
| **涅槃回复** | 整个人被火焰吞没一瞬间——不是燃烧，是火焰从体内涌出又立刻收回。皮肤上的裂纹全部亮起后暗下去，站起来的时候纹路重新稳定。像换了一口气 |
