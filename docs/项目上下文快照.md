## 2026-07-16 最新用户窗口反馈

- `BUG-20260716-003`：CardReward “跳过”当前会调用 `TrySkipBattleCardReward` 并删除胜利页奖励行。冻结口径：跳过只关闭 CardReward overlay；奖励行保留并恢复可点；不写永久牌组、不消费奖励槽。
- 奖励候选生成事实：`RewardResolver` 在胜利计划建立时，从 `CardPoolCatalog` 复制卡池，用节点 Reward 命名随机流稳定洗牌，截取 `CandidateCount` 后写入不可变 `RewardPlan.Candidates`。UI 打开只读取该计划，因此重复打开不得重抽或换序。
- 当前额外风险：CardReward UI 的 `selectedCount/selectedIndices` 是每次 `Show` 新建的本地状态。ChoiceCount > 1 的部分领取场景重新打开时，必须从 GameManager 已领取索引恢复，不得只依赖本地变量。
- `P1-019`：地图后续层不可见。需要共享横向视口，支持滚轮横移和左键拖拽，拖拽与节点点击有阈值隔离；动画改为固定左起点从左向右揭示，不再从右侧抽屉滑入。
- `BUG-20260716-004`：Lingmai/Shop/Event 等仍通过 `GoToScene(Map)` 清理当前节点页，可能露出无价值底页。冻结口径：继续/返回地图只开 overlay；关闭恢复同一页面；节点效果完成后按钮灰显；只有点击合法下一节点才离场。
- QA 下一轮必须全量枚举 UI 按钮回调，重点搜索 `GoToScene("...Map...")`、`QueueFree/Hide/Clear`、奖励放弃/领取、NodeResult/Exit 调用和空白页错误路径。按钮存在超出显示文案的隐藏状态变更按 P0 阻断。

## ACT1 冻结口径

- 区域：第一大关“不周废墟”，9 层分层 DAG；Layer 1~3 为弱怪，Layer 8 为相柳之骸。
- 敌人：弱怪为山野妖猴、碎石山精、掠灵散修；强怪为不周残兵、符阵散修、山魈王；关底为相柳之骸。
