## v0.0.1-alpha 范围

必须有：

- 标题界面可进入游戏和退出。
- 角色选择默认巫祝，其余角色锁定但可见。
- MapScene 显示道韵 3 选 1，固化后解锁地图节点。
- 战斗可以抽牌、出牌、结束回合、敌人行动、胜利和失败。
- 胜利弹窗可领取灵韵、打开卡牌奖励、继续查看地图。
- CardReward overlay 选卡后回到胜利弹窗或地图流程。
- `dotnet build .\AfterHongHuang.csproj` 通过。

暂不做：

- 正式商店
- 正式存档
- 多角色完整卡池
- 多区域完整关卡
- 联机
- 完整音频系统

## 发布流程

每次准备发布版本时执行：

1. 开发部确认工程可编译。
2. UI/UX部按 `验收清单.md` 进行主流程检查。
3. 策划部确认玩法表现没有偏离 MVP 需求。
4. 美术部确认资源缺失不会影响基本理解。
5. 总项目经理汇总已知问题和风险。
6. 更新版本号、开发记录和发布说明。
7. 导出可运行包。

## v0.0.1-alpha | 2026-07-10

### 新增
- 建立 Windows 可玩包导出流程。
- 生成 `v0.0.1-alpha` 便携 zip 包。

### 修复
- 本版本包含 P0-012 手牌交互返工与 BUG-20260709-001~004 修复。

### 调整
- 新增最小 Windows Desktop 导出 preset。
- 安装 Godot `4.7.stable.mono` 导出模板。

### 验证
- `dotnet build .\AfterHongHuang.csproj`：0 错误 / 0 警告。
- Godot headless 启动：通过，`GameManager` Autoload 初始化。
- Windows release 导出：通过，产物位于 `洪荒之后-code/build/v0.0.1-alpha/`，并生成 `data_AfterHongHuang_windows_x86_64/` 运行目录。
- zip 烟测：`AfterHongHuang-v0.0.1-alpha-windows.zip` 现包含 `AfterHongHuang.exe`、`AfterHongHuang.pck` 与 `data_AfterHongHuang_windows_x86_64/`。
- 可见窗口烟测：通过，窗口标题为 `AfterHongHuang`，主窗口句柄非零；同时保留了 `AfterHongHuang-smoke.png` 作为截图证据。
- 主流程验收：仍建议用户做一次正常双击试运行以完成最终体验确认，但当前导出包已不再是“仅 exe/pck”坏包。

### 已知问题
- 旧的坏包已移入 `洪荒之后-code/build/failed/v0.0.1-alpha/AfterHongHuang-v0.0.1-alpha-windows-broken.zip`，正式 zip 已重打。
- 当前仍是 MVP 占位美术与动态 UI 阶段，正式演示前需要继续替换资源并做完整发布前回归。
