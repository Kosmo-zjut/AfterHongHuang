## 1. 语言选择

本项目采用 **C#** 作为主开发语言，理由如下：

- C# 在 AI 模型训练数据中占比远高于 GDScript，AI Agent 生成代码质量更稳定
- 强静态类型系统在编译期捕获错误，减少运行时调试成本
- 丰富的 .NET 生态（LINQ、Collections、Task 异步）
- Godot 4.x 对 C# 的支持已成熟，API 绑定完整

### 1.1 环境要求

- Godot 4.7 **.NET 版本**（非标准版）
- .NET SDK 8.0+
- IDE：推荐 JetBrains Rider 或 VS Code + C# Dev Kit

## 2. C# 代码风格

遵循 [Microsoft C# Coding Conventions](https://learn.microsoft.com/en-us/dotnet/csharp/fundamentals/coding-style/coding-conventions) 并结合 Godot 特定约定。

### 2.1 命名规范

| 元素 | 风格 | 示例 |
|------|------|------|
| 类/结构体 | PascalCase | `PlayerController`, `EnemyAI` |
| 接口 | `I` 前缀 + PascalCase | `IInteractable`, `IDamageable` |
| 枚举类型 | PascalCase | `GameState`, `ItemType` |
| 枚举值 | PascalCase | `GameState.Playing`, `ItemType.Weapon` |
| 方法 | PascalCase | `TakeDamage()`, `GetNearestEnemy()` |
| 属性 | PascalCase | `Health`, `MaxSpeed` |
| 私有字段 | `_camelCase` | `_currentHealth`, `_targetPosition` |
| 静态字段 | `s_camelCase` | `s_instance`, `s_maxPlayers` |
| 常量 | PascalCase | `MaxHealth`, `DefaultGravity` |
| 局部变量 | camelCase | `enemyCount`, `isAlive` |
| 参数 | camelCase | `damage`, `targetNode` |
| Godot 导出属性 | PascalCase | `[Export] public float MoveSpeed { get; set; }` |
| 信号 | PascalCase (C# event) | `event Action<int> HealthChanged;` |

### 2.2 文件组织

每个文件只包含一个主要类。文件名与类名一致。

```
scripts/
├── Core/
│   ├── GameManager.cs
│   └── EventBus.cs
├── Entities/
│   ├── Player/
│   │   ├── PlayerController.cs
│   │   ├── PlayerStats.cs
│   │   └── PlayerAnimation.cs
│   └── Enemy/
│       ├── EnemyBase.cs
│       └── EnemyAI.cs
```

### 2.3 代码格式

```csharp
// 使用 4 空格缩进，不使用 Tab
// 左花括号不换行（K&R 风格）
public class PlayerController : CharacterBody3D
{
    // 导出属性在前
    [Export] public float MoveSpeed { get; set; } = 5.0f;
    [Export] public float JumpVelocity { get; set; } = 4.5f;
    
    // 私有字段
    private Vector3 _velocity;
    private bool _isOnFloor;
    
    // Godot 生命周期方法
    public override void _Ready()
    {
        // 初始化逻辑
    }
    
    public override void _PhysicsProcess(double delta)
    {
        HandleMovement(delta);
    }
    
    // 私有方法
    private void HandleMovement(double delta)
    {
        // 具体逻辑
    }
}
```

### 2.4 注释规范

```csharp
/// <summary>
/// 对玩家造成伤害，并触发受击反馈
/// </summary>
/// <param name="damage">伤害值</param>
/// <param name="source">伤害来源节点</param>
public void TakeDamage(float damage, Node source)
{
    _currentHealth -= damage;
    
    // 触发受击动画（TODO: 改为信号方式解耦）
    _animationPlayer.Play("hit");
    
    if (_currentHealth <= 0)
    {
        Die();
    }
}
```

- 公共 API 使用 XML 文档注释（`///`）
- 复杂逻辑使用行注释解释**为什么**这样做，而非**做了什么**
- 临时方案/TODO 必须标注 `// TODO:`

## 3. 节点架构设计

### 3.1 核心原则

1. **组合优于继承**：优先使用子节点组合功能，而非深层继承链
2. **场景复用**：通用功能封装为独立场景（PackedScene），通过实例化复用
3. **信号解耦**：跨系统通信使用信号（C# Event / Godot Signal），避免直接依赖
4. **单一职责**：每个脚本只负责一个明确的功能领域

### 3.2 典型节点结构示例

```
Player (CharacterBody3D)
├── CollisionShape3D          # 碰撞体
├── MeshInstance3D            # 模型
├── AnimationPlayer           # 动画控制
├── CameraMount (Node3D)      # 相机挂点
│   └── Camera3D              # 跟随相机
├── StateMachine (Node)       # 状态机（子节点管理）
│   ├── IdleState
│   ├── RunState
│   └── AttackState
└── InteractionArea (Area3D)  # 交互检测区域
    └── CollisionShape3D
```

### 3.3 场景继承

当多个实体共享相同基础结构时使用场景继承：

```
BaseEnemy.tscn                  # 敌人基类场景
├── EnemyHealthBar.tscn  ← 继承  
├── EnemyMelee.tscn      ← 继承  
└── EnemyRanged.tscn     ← 继承  
```

### 3.4 推荐使用原生节点

| 需求 | 推荐节点 | 避免 |
|------|----------|------|
| 2D 精灵动画 | `AnimatedSprite2D` | 自定义帧动画系统 |
| 粒子效果 | `GPUParticles3D` / `CPUParticles3D` | 自建粒子系统 |
| 路径移动 | `Path3D` + `PathFollow3D` | 手动贝塞尔计算 |
| 补间动画 | `Tween` (内置) | DOTween 等第三方库 |
| UI 布局 | `Container` 系列 | 手动计算坐标 |

## 4. 性能规范

### 4.1 对象池

频繁生成/销毁的实体（子弹、粒子、掉落物）必须使用对象池：

```csharp
public class ObjectPool<T> where T : Node
{
    private readonly Queue<T> _pool = new();
    private readonly PackedScene _prefab;
    
    public T Get() { /* ... */ }
    public void Return(T obj) { /* ... */ }
}
```

### 4.2 避免在 `_Process` 中做重计算

```csharp
// ❌ 错误：每帧查找
public override void _Process(double delta)
{
    var enemies = GetTree().GetNodesInGroup("enemy"); // 每帧遍历场景树
}

// ✅ 正确：缓存 + 按需更新
private Godot.Collections.Array<Node> _enemies;

public override void _Ready()
{
    _enemies = GetTree().GetNodesInGroup("enemy");
    // 通过信号监听 enemy 组变化时更新 _enemies
}
```

### 4.3 VisibilityNotifier 控制生命周期

远离玩家的实体通过 `VisibleOnScreenNotifier3D` 暂停逻辑：

```csharp
public partial class Enemy : CharacterBody3D
{
    private void OnScreenExited()
    {
        SetProcess(false);
        SetPhysicsProcess(false);
    }
    
    private void OnScreenEntered()
    {
        SetProcess(true);
        SetPhysicsProcess(true);
    }
}
```
