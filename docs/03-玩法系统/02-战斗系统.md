> 对标：杀戮尖塔2战斗框架。

## 1. 回合流程

```
  玩家回合开始
    │
    ▼
  玩家回合（自由出牌）
    │
    ▼
  玩家回合结束结算
    ├── 灼烧/毒素等扣血
    ├── 护体归零
    ├── 灵力残余清零
    └── 其他"回合结束"触发效果
    │
    ▼
  敌人回合开始
    ├── 敌人消耗意图，执行攻击/技能
    └── 敌人"回合开始"触发效果结算
    │
    ▼
  敌人回合结束结算
    ├── 敌人灼烧/毒素等扣血
    ├── 敌人"回合结束"触发效果
    └── 敌人护体归零
    │
    ▼
  玩家回合开始（循环）
```

> 关键差异：玩家回合结束在前，敌人回合在后。玩家的"回合结束 buff/debuff 结算"发生在敌人行动之前。

## 2. 核心属性

### 2.1 玩家属性

| 属性 | 初始值 | 说明 |
|------|:--:|------|
| **生命上限** | 80 HP（巫祝） | 可通过法宝/道痕增加 |
| **当前生命** | = 生命上限 | 开局满血。归零 = 本局失败 |
| **基础灵力** | 3 点/回合 | 全角色通用。每回合开始时补满 |
| **灵力上限** | 6 点 | 可通过法宝/道行提升 |

### 2.2 敌人属性

| 属性 | 说明 |
|------|------|
| **生命** | 归零即死亡 |
| **意图** | 敌人头顶显示的本回合计划动作 |
| **护体** | 同玩家，回合结束时消失 |

---

## 3. 护体机制

| 规则 | 说明 |
|------|------|
| **生效范围** | 本回合内有效 |
| **结算时机** | 回合结束时**完全清零** |
| **叠加** | 多次获得护体可以叠加（如打两张格挡 → 5+5=10点护体） |
| **抵挡** | 护体先于生命承受伤害。护体不足 → 剩余穿透到生命 |

> 护体不会留到下一回合。

---

## 4. 伤害公式

```
实际伤害 = (卡牌面板伤害 + 斗劲层数) × 易损修正 × 虚弱修正
```

| 修正项 | 规则 |
|------|------|
| **斗劲** | 每层 +1 伤害，持续整局 |
| **易损** | 伤害 ×1.5（每层易损持续1个目标回合） |
| **虚弱** | 伤害 ×0.75 |
| **多重修正** | 乘法叠加（如同时有易损+虚弱 → ×1.5 × 0.75 = ×1.125） |

> 伤害计算结果取整数，向下取整。

## 5. 胜负条件

| 结果 | 条件 |
|:--:|------|
| **胜利** | 所有敌人 HP 归零 |
| **失败** | 玩家 HP 归零 → 本局结束，可通过时空印记重开 |

## 6. 敌人意图系统

对标杀戮尖塔的 Intent 机制。敌人头顶显示本回合将执行的行动：

| 意图类型 | 图标方向 | 说明 |
|:--:|------|------|
| **攻击** | 剑形 | 造成 N 点伤害 |
| **强化** | 升腾状 | 本回合不攻击，给自己叠 buff / 获得护体 |
| **特殊** | 符箓状 | 施加 debuff / 召唤 / 其他特殊技能 |

> 意图**可以被预判**——玩家在自己的回合一看到敌人意图，就可以决定出牌策略。

### 6.1 意图展示契约

每个敌人意图必须由 `EnemyDefinition.IntentSequence` 提供以下字段，UI 只读取数据，不根据敌人名或意图名自行推断效果：

| 字段 | 要求 |
|------|------|
| `IntentId` | 稳定 ID，供状态机结算和日志追踪 |
| `DisplayName` | 项目内显示名称，例如“伏石”“掷石” |
| `IntentType` | 攻击、强化或特殊 |
| `PreviewSummary` | 本回合效果摘要，必须包含伤害、护体、状态或无攻击说明 |
| `EffectDefinition` | 实际结算字段；预览文本不得成为唯一规则来源 |

诗性名称可以保留作为 `DisplayName`，但不得缺少 `PreviewSummary`。例如“伏石”必须显示为“本回合不攻击，获得 8 点护体”，而不是只显示“伏石”。

## 7. 怪物池体系

对标杀戮尖塔的怪物生成规则：

### 7.1 池子分级

| 池子 | 说明 | 出现时机 |
|:--:|------|------|
| **弱怪池** | 该关基础敌人，战力较低 | 第一大关前 3 场；其余大关前 2 场 |
| **强怪池** | 战力较强的常规敌人 | 弱怪场次之后的所有普通战斗 |
| **精英池** | 高战力高回报 | 地图精英节点（另算，不进入弱/强顺序） |

### 7.2 奖励规则

每次击败敌人（普通/精英/Boss）：

| 奖励 | 说明 |
|------|------|
| **卡牌奖励** | 3 选 1，含概率补正。详见 [01-卡牌系统](./01-卡牌系统.md) §5 |
| **灵韵** | 游戏内货币（暂定名），对标杀戮尖塔金币。普通敌人少量，精英中等，Boss大量 |

> 灵韵（暂定）用途：行脚宝商处购买卡牌/法宝/药水；特定事件消耗。

| 术语 | 类型 | 效果 | 持续 |

## 9. 第一个敌人：山野妖猴

> MVP验证专用。不周废墟外围最常见的妖物——被天崩后的灵气吸引而来，在废墟碎石间徘徊的低阶妖兽。

### 基础数据

| 属性 | 值 |
|------|:--:|
| **名称** | 山野妖猴 |
| **阵营** | 妖 |
| **HP** | 60 |
| **体型** | 单怪（1只） |
| **属于** | 弱怪池 |

### 意图循环

山野妖猴的意图：

| 回合 | 意图 | 效果 |
|:--:|:--:|------|
| 1 | **嬉斗**（强化） | 本回合不攻击；执行结算后激活**灵猴闪避**，计数显示为 `0/3` |
| 2+N | 交替循环 **打7** → **打13** | 第2回合打7，第3回合打13，第4回合打7，第5回合打13… |

### 灵猴闪避机制

- 战斗开始时 `MechanicId=monkey_dodge` 未激活，`DodgeHitCount=0` 仅作为内部初值；UI 不显示灵猴闪避、计数器或“0/3”。
- 只有山野妖猴执行并结算“嬉斗”后，机制才变为激活，并向玩家显示 `灵猴闪避 0/3`。
- 机制激活后，每次被斗击牌命中（无论伤害为多少，护体完全抵挡不算命中），计数器 +1。
- 当计数器达到 3 时，该次斗击伤害变为 0，随后计数器重置为 `0/3`。
- 若后续定义让山野妖猴再次执行“嬉斗”，该次只负责刷新机制并重置为 `0/3`；当前 ACT1 序列不会重复“嬉斗”。
- 术法牌（不含斗击标签的牌）不受闪避影响。
- 非山野妖猴的 `EnemyDefinition` 不得声明或消费 `monkey_dodge`、`DodgeHitCount`，不得通过默认值激活该机制。

### 9.1 “伏石”语义确认

ACT1 的 `act1_weak_stone` 使用“伏石”作为强化意图：本回合不攻击，获得 8 点护体。若该护体在玩家回合被完全打破，敌人下一次意图改为“碎岩：造成 12 点伤害”；若未被打破，则按普通序列进入“掷石：造成 7 点伤害”。当前玩法文档与本次任务提供的“获得 8 护体”口径一致，未发现数值冲突。

### 9.2 击败奖励

| 奖励 | 值 |
|------|:--:|
| 卡牌 | 3 选 1（来自巫祝奖赏卡池） |
| 灵韵 | 10~15 |
