# 10-道痕系统

> 版本: 1.5.0 | 状态: ✅ 已完成（附录池待填充效果） | 最后更新: 2026-07-05
>
> 对标：杀戮尖塔的"首领遗物"机制。道痕独立于常规法宝体系，只能在关卡过渡时获得，不能从商店/事件/宝箱中获取。

---

## 世界观设定

遗荒的每一片区域都死过太多大能。祖巫的愤怒、妖圣的不甘、千万修士的执念——这些残存意志破碎成无数**道韵碎片**，漂浮在废墟的灵气中。

遗荒是一个"同心圆"结构：越靠近帝江裂缝的核心，灵气浓度越高、煞气越重、法则残片越密集。外围只能承载较弱逝者的道韵，核心区域则沉淀着祖巫天帝级别的碎片。

当你穿过一片区域、向遗荒更深处迈进时，所处环境的道韵浓度会骤然变化。你体内的时空印记（帝江+烛九阴法则碎片）与当前深度匹配的新道韵碎片共鸣——三道残响从时空乱流中浮现，其中一枚会与你格外契合。你可以选择将它**固化**，凝聚为一件蕴含法则之力的法宝。

> 这些法宝不是"战利品"——你从旧时代的尸体中挑了一件遗物来陪你走完剩下的路。

## 核心规则

| 规则 | 说明 |
|------|------|
| **触发时机** | 每次穿过大关进入下一关时（开局→Act1之间、Act1→Act2之间、Act2→Act3之间、Act3→Final之间）。共4次触发机会 |
| **选择方式** | 3选1，选中后固化，剩余两枚消散 |
| **专属池** | 道痕池独立于常规法宝池——不能从商店/事件/宝箱中获取，反之亦然 |
| **不可跳过** | 必须选择一枚固化（无法拒绝——时空印记会自动吸附最契合的碎片） |
| **角色通用** | 每个角色的道痕池相同（当前版本），后续可加入角色专属道痕 |
| **与Boss无关** | 道痕来自区域的整体道韵浓度，不来自具体被击败的Boss。无论碰到哪个Boss，该关过渡时的道痕池相同 |
| **品级锁定** | 池子按遗荒深度分三品：开局取下品池 → 首次过渡取中品池 → 后两次过渡取上品池 |

## 道痕与常规法宝的区分

| 维度 | 道痕 | 常规法宝 |
|------|------|------|
| **对标** | 杀戮尖塔"首领遗物" | 杀戮尖塔普通遗物 + 商店遗物 + 事件遗物 |
| **获取方式** | 仅关卡过渡时 3选1 固化（共4次：开局/Act1→2/Act2→3/Act3→Final） | 商店/事件/宝箱/精英掉落 |
| **强度** | 效果通常更强大，带全局/战斗级加成 | 效果多样，从数值加成到机制改变 |
| **数量/局** | 4件（开局1件 + 每关过渡1件） | 15-25件不等 |
| **不可重复** | 同一道痕一局内不会重复出现 | 同一法宝可能多次获得 |
| **世界观** | 大能死后残留的法则道韵 | 散落在废墟中的有形法宝 |

## 未来扩展

- **角色专属道痕**：每个角色在Act 3有1-2件专属道痕（替换池内随机位），与角色背景故事呼应
  - 例：巫祝专属道痕——"九凤的旧披风"（效果待设计）
- **道痕合成**：集齐同一祖巫的多个道痕后自动合成强化效果（类似塔1的"集齐条件遗物"）
- **负面道痕**：极低概率出现带负面效果但极强的道痕——"弑神枪残锋"式设计
