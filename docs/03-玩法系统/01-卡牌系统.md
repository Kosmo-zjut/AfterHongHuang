## 1. 卡牌类型

| 类型 | 名称 | 对应 | 说明 |
|:--:|:--:|:--:|------|
| **斗击** | 攻击牌 | Attack | 直接或间接造成伤害，是消灭敌人的主要手段 |
| **术法** | 技能牌 | Skill | 提供格挡、增益、控场、抽牌等辅助效果。打出后进入弃牌堆 |
| **道行** | 能力牌 | Power | 打出后在本场战斗中永久生效（不进入弃牌堆） |
| **劫数** | 诅咒牌 | Curse | 不可主动打出，滞留在手牌中占用抽牌位。必须通过特定卡牌或商店移除 |

### 1.1 类型命名逻辑

四个词均取自修仙语境，直觉可理解：

- **斗击** —— 斗法中的直接攻击，干脆利落
- **术法** —— 施展术法，修仙中泛指非攻击的道法手段
- **道行** —— 修道成果，"道行深"即能力强，永久生效
- **劫数** —— "在劫难逃"，命中注定的拖累

## 2. 卡牌数据结构

每张卡牌由以下字段定义：

| 字段 | 类型 | 说明 |
|------|------|------|
| **ID** | string | 唯一标识符，如 `wx_01` |
| **名称** | string | 卡牌显示名称，如"雷霆一击" |
| **类型** | enum | 斗击 / 术法 / 道行 / 劫数 |
| **角色** | enum | 巫祝 / 盗宝者（空=多角色通用） |
| **费用** | int | 打出所需灵力值（0~X，X=需要消耗所有剩余灵力） |
| **稀有度** | enum | 黄品 / 玄品 / 地品 / 天品 |
| **描述** | string | 效果文字描述 |
| **数值** | int | 主要效果数值（伤害/格挡量等） |
| **关键词** | string[] | 关联的关键词标签 |
| **升级后** | string | 升级后的卡牌ID（升级=自动替换为另一张卡） |
| **背景文本** | string | 卡牌底部的洪荒背景小字（可选，纯装饰） |

### 2.1 卡牌背景文本示例

每张卡牌底部有一行洪荒背景文字，增加沉浸感：

> **烈拳**（巫祝）—— "祝融死前最后一道重击，砸穿了帝俊的一只金乌羽。"

## 3. 费用体系

### 3.1 灵力（对应塔2的能量/法理）

| 属性 | 值 |
|------|:--:|
| 基础灵力 | 每回合 3 点 |
| 道行/法宝可增加 | 上限 3 点（即最高每回合 6 点） |

### 3.2 费用范围

| 费用 | 说明 | 典型用途 |
|:--:|------|------|
| 0 | 免费 | 最简单的基础卡、初始卡组填充 |
| 1 | 轻巧 | 基础攻防 |
| 2 | 标准 | 较强效果 |
| 3 | 重击 | 强力卡牌 |
| X | 全部剩余灵力 | 爆发性卡牌，灵力越多越强 |

## 4. 稀有度分布（天地玄黄）

取自《千字文》开篇"天地玄黄，宇宙洪荒"——与本作标题同源。

| 稀有度 | 名称 | 出现概率（非基础卡池） | 对应塔2 | 说明 |
|:--:|:--:|:--:|------|------|
| 黄 | **黄品** | 不出现（仅初始卡组） | Basic | 每个角色自带的起始卡牌。天玄地黄，黄为根基 |
| 玄 | **玄品** | 70% | Common | 战后最常见奖励。玄者幽远，大道初窥 |
| 地 | **地品** | 25% | Uncommon | 较强效果。地载万物，厚积薄发 |
| 天 | **天品** | 5% | Rare | 强力效果，稀有。天行健，至强至珍 |

> 不设"神话级"卡牌——最高稀有度留给法宝系统。

## 5. 各角色简要卡牌方向

> **Demo阶段**：只开发巫祝+凡人两个角色的完整卡池。其余角色仅保留方向描述，待后续开发。

| 角色 | Demo状态 | 核心机制 | 方向摘要 |
|------|:--:|------|------|
| **巫祝** | ✅ 开发 | 自伤觉醒+涅槃 | 祝融血脉·自燃觉醒。自伤扣血→蓄力爆发+火伤,低血量可涅槃回复 |
| **凡人** | ✅ 开发 | 明悟·蒙昧 | 盲猜抽牌属性：猜中奖励、猜错惩罚 |
| **盗宝者** | ⏳ 预览 | 法宝联动 | 每有一件法宝，卡牌效果增强 |
| **截教门徒** | ⏳ 预览 | 阵眼·连携 | 打出"阵眼牌"后"连携牌"触发额外效果 |
| **金乌遗孤** | ⏳ 预览 | 双形态（人/妖） | 每回合选择人形或妖形，两边卡牌不同 |

## 6. 卡牌升级

- 每张卡牌都有升级版本（设计另一张卡，ID以 `_p` 结尾）
- 升级方式：散修的笔记（普通级法宝）、事件、休息节点的"悟道"选项
- 升级后卡牌会替换原版，性能和费用可能改变

## 7. 初始卡组规则

每个角色初始卡组 10 张：

| 构成 | 数量 | 说明 |
|------|:--:|------|
| 基础斗击 | 4 | 1费，固定伤害6（黄品） |
| 基础术法 | 4 | 1费，固定格挡5（黄品） |
| 角色专属卡 | 2 | 与该角色核心机制挂钩，具体到角色设计时定义（黄品） |

> 部分角色初始可能含有劫数（如凡人）——具体在角色卡池设计中确定。

## 9. 术语对照表

| 塔2 | 洪荒之后 | 含义 | 状态 |
|------|:--:|------|:--:|
| Strength | **斗劲** | 攻击伤害+1每层 | ✅ |
| Vulnerable | **易损** | 受到的攻击伤害+50%，持续1-3回合 | ✅ |
| Weak | 虚弱 | 造成的伤害-25%，持续1-3回合 | ⏳ 占位 |
| Block | **护体** | 本回合抵挡等量伤害，回合结束清零 | ✅ |
| Energy | **灵力** | 每回合可用行动点 | ✅ |
| Exhaust | **消弭** | 本场战斗中移除此牌，不再参与循环 | ✅ |
| Dexterity | 灵巧 | 护体牌获得的护盾+1每层 | ⏳ 占位 |
| Poison | 毒素 | 每回合开始时失去N血，然后层数-1 | ⏳ 占位 |
| Burn | 灼烧 | 不可打出，回合结束时失去2血，自动消弭 | ⏳ 占位 |
| Ritual | 祭祀 | 每回合开始时获得N斗劲 | ⏳ 占位 |
| Thorns | 荆棘 | 受攻击时对攻击者造成等量反伤 | ⏳ 占位 |
| Intangible | 无形 | 所有伤害和生命损失降至1，持续1回合 | ⏳ 占位 |
| Artifact | 定力 | 免疫一次负面状态 | ⏳ 占位 |
| Frail | 脆弱 | 护体牌效果-25% | ⏳ 占位 |
