## 1. 卡牌类型

| 类型 | 名称 | 对应 | 说明 |
|:--:|:--:|:--:|------|
| **斗击** | 攻击牌 | Attack | 直接或间接造成伤害，是消灭敌人的主要手段 |
| **术法** | 技能牌 | Skill | 提供格挡、增益、控场、抽牌等辅助效果。打出后进入弃牌堆 |
| **道行** | 能力牌 | Power | 打出后在本场战斗中永久生效（不进入弃牌堆） |
| **劫数** | 诅咒牌 | Curse | 不可主动打出，滞留在手牌中占用抽牌位。必须通过特定卡牌或商店移除 |

### 1.1 类型命名逻辑

四个词均取自修仙语境，直觉可理解：

- **斗击** —— 斗法中的直接攻击，干脆利落
- **术法** —— 施展术法，修仙中泛指非攻击的道法手段
- **道行** —— 修道成果，"道行深"即能力强，永久生效
- **劫数** —— "在劫难逃"，命中注定的拖累

## 2. 卡牌数据结构

每张卡牌由以下字段定义：

| 字段 | 类型 | 说明 |
|------|------|------|
| **ID** | string | 唯一标识符，如 `wx_01` |
| **名称** | string | 卡牌显示名称，如"雷霆一击" |
| **类型** | enum | 斗击 / 术法 / 道行 / 劫数 |
| **角色** | enum | 巫祝 / 盗宝者（空=多角色通用） |
| **费用** | int | 打出所需灵力值（0~X，X=需要消耗所有剩余灵力） |
| **稀有度** | enum | 黄品 / 玄品 / 地品 / 天品 |
| **描述** | string | 效果文字描述 |
| **数值** | int | 主要效果数值（伤害/格挡量等） |
| **关键词** | string[] | 关联的关键词标签 |
| **升级后** | string | 升级后的卡牌ID（升级=自动替换为另一张卡） |
| **背景文本** | string | 卡牌底部的洪荒背景小字（可选，纯装饰） |

### 2.1 卡牌背景文本示例

每张卡牌底部有一行洪荒背景文字，增加沉浸感：

> **烈拳**（巫祝）—— "祝融死前最后一道重击，砸穿了帝俊的一只金乌羽。"

## 4. 稀有度分布（天地玄黄）

取自《千字文》开篇"天地玄黄，宇宙洪荒"——与本作标题同源。

| 稀有度 | 名称 | 出现概率 | 对应塔2 | 说明 |
|:--:|:--:|:--:|------|------|
| 天 | **天品** | 不出现在常规卡池 | Ancient（先古卡） | 天行健，至强至珍。只能通过 Boss 战、特定事件、道痕固化等特殊途径获得 |
| 地 | **地品** | 5% | Rare（金卡） | 强大效果，稀有。地载万物，厚积薄发 |
| 玄 | **玄品** | 25% | Uncommon（蓝卡） | 较强效果，构筑核心。玄者幽远，大道初窥 |
| 黄 | **黄品** | 70% | Common（白卡）+ Basic（初始卡） | 最常见战利品；也是每个角色的起始卡牌。天玄地黄，黄为根基 |

> 塔2 先古卡 = 我们设"天品"：不出现在战后常规卡池，获取方式极其有限（Boss 战 3 张全金 = 3 张天品任选 1、事件赠予、道痕固化等）。
>
> 黄品包含初始卡组的所有卡牌（10 张起始卡），这些卡牌也不会出现在常规卡池中。

## 5. 卡牌奖励机制

> 对标：杀戮尖塔的战后卡牌奖励。每次击败普通敌人/精英/Boss后触发。
> 杀戮尖塔2沿用了尖塔1的核心算法，以下结合洪荒设定进行适配。
>
> **MVP 阶段简化**：巫祝正式最小奖赏卡池见 [§10](#10-巫祝-mvp-奖赏卡池正式最小方案)。当前代码若仍使用 `RewardCardPool`（拳袭/格挡/烈拳/燃血）属于待接入状态。稀有度补正（rareOffset）、精英加成、升级概率等可暂不接入，不影响先用固定 MVP 池替换占位卡池。

### 5.1 基础流程

1. 击败敌人后，系统从该角色卡池中按稀有度**依次抽取 3 张**（互不重复）
2. 玩家**3 选 1**，选中的卡牌加入牌组
3. 未被选中的 2 张弃掉，不进入牌库

> 可以不选直接关闭 overlay 进入下一节点——等同于跳过，意味着永不再见这 3 张。对标尖塔2：跳过不是独立按钮，不选本身即为跳过。

### 5.2 稀有度概率（常规卡池）

| 洪荒稀有度 | 对应 | 基础概率 | 说明 |
|:--:|:--:|:--:|------|
| **地品** | Rare（金卡） | 5% | 整局稀有，强力效果 |
| **玄品** | Uncommon（蓝卡） | 25% | 构筑核心，技能牌主力 |
| **黄品** | Common（白卡） | 70% | 最常见，填曲线 |

> **天品**不出现在常规卡池中。Boss 战的三张奖励全为天品——这是玩家最稳定的天品卡来源。
> 初始卡组中的黄品卡（如"拳袭""格挡"）也不出现在战后奖励中。

### 5.3 概率补正机制（rareOffset）

> 尖塔源码解析：`rareOffset` 是一个动态修正值，确保玩家**不会长时间见不到地品（金卡）**。

| 事件 | rareOffset 变化 | 效果 |
|------|:--:|------|
| 进入新关卡 | 重置为 0 | 地品概率回到基础 5% |
| 抽到一张黄品卡 | +1 | 地品概率 +1%（黄品 -1%，玄品不变） |
| 抽到一张地品卡 | 重置为 -5 | 地品概率降到 0%（-5 + 5 = 0），避免连出地品 |
| 抽到一张玄品卡 | 不变 | 玄品始终 25% 固定 |

**实例演化**：

| 状态 | 地品 | 玄品 | 黄品 |
|------|:--:|:--:|:--:|
| 新关卡起 | 5% | 25% | 70% |
| 连续 3 次出黄品后 | 8% | 25% | 67% |
| 连续 10 次出黄品后 | 15% | 25% | 60% |
| 终于出地品 → 重置 | 0% | 25% | 75% |
| 上限（40%） | 40% | 25% | 35% |

> rareOffset 上限为 +35（基础5%+35%=40%地品）。玄品始终占 25%，黄品作为"弹性填充"吸收地品的波动。

### 5.4 精英战奖励

击败精英后，地品概率获得 **+10% 额外加成**：

| 状态 | 地品 | 玄品 | 黄品 |
|------|:--:|:--:|:--:|
| 精英战初始 | 15% | 25% | 60% |
| 精英战上限 | 50% | 25% | 25% |

### 5.5 Boss战奖励

- Boss战的三张奖励卡**全部为天品卡**（3选1选一张天品）
- 不受 rareOffset 补正影响——固定全金

### 5.6 卡牌升级概率

战后的卡牌有概率直接出现**已升级版**（跳过消耗灵脉节点的"精进道行"步骤）：

| 关卡 | 升级概率 |
|------|:--:|
| 第一关（不周废墟） | 0% |
| 第二关（太阳残宫） | 12.5% |
| 第三关（都天神渊） | 25% |

### 5.7 抽选规则

- 3 张卡**顺序抽选**（非同时），每张的稀有度受前一张的 rareOffset 影响
- **同一奖励中不会出现两张同名卡**
- 卡牌来自**当前角色的卡池**（含通用卡 + 角色专属卡）
- 天品（先古卡）不出现在战后常规卡池中——Boss 战是主要获取途径
- 劫数（诅咒卡）不出现在奖励中——只能通过事件/特定敌人施加

## 7. 卡牌升级

- 每张卡牌都有升级版本（设计另一张卡，ID以 `_p` 结尾）
- 升级方式：散修的笔记（普通级法宝）、事件、灵脉节点的**精进道行**选项
- 升级后卡牌会替换原版，性能和费用可能改变

### 7.1 精进道行规则

灵脉节点选择**精进道行**时，玩家从当前牌组中选择 1 张存在升级版的卡牌，结算后永久替换为对应升级版。若当前牌组没有任何可升级卡，该选项禁用并提示"暂无可精进的卡牌"，不会消耗灵脉节点。

## 10. 巫祝 MVP 奖赏卡池（正式最小方案）

### 10.1 设计目标

本池用于替代"战后奖励暂用初始卡"的占位方案，优先服务第一轮 MVP 闭环：

- 总量 10 张，控制实现量和测试量。
- 只使用已定义状态与效果：伤害、护体、斗劲、易损、永炎、自损、消弭。
- 不新增关键词，不改变现有战后奖励概率机制。
- 初始卡组中的拳袭、格挡、烈拳、燃血不进入本池，避免玩家反复拿到起始牌。
- 常规战后池不放天品卡；ACT1 Boss 专属天品池见 §10.7。天品仍不进入普通战后抽取。
- MVP 先不做升级版，后续统一按 `_p` 规则补。

### 10.2 池结构

| 品级 | 数量 | 定位 |
|:--:|:--:|------|
| **黄品** | 6 | 替代初始攻防，提供基础曲线和少量自损取舍 |
| **玄品** | 3 | 强化巫祝核心流派：自损换斗劲、易损爆发、高额护体 |
| **地品** | 1 | 稀有强牌，提供永炎路线入口 |
| **天品** | 0 | 不进入常规战后池；ACT1 Boss 专属池单独定义 |

### 10.3 卡牌清单

|------|------|:--:|:--:|:--:|------|------|------|
| `wx_r_001` | **燎掌** | 黄品 | 斗击 | 1 | 造成 8 点伤害。 | 替代拳袭的基础进攻卡，让奖励池有直接变强感。 | 数值高于拳袭但无附加效果；若早期伤害过高可降至 7。 |
| `wx_r_002` | **碎骨拳** | 黄品 | 斗击 | 1 | 造成 5 点伤害，施加 1 层**易损**。 | 给玩家低成本易损入口，配合后续斗击爆发。 | 易损过多会放大爆发；MVP 先控制为 1 层。 |

| `wx_r_007` | **焚脉重拳** | 玄品 | 斗击 | 2 | 失去 2 点生命，造成 11 点伤害，施加 2 层**易损**。 | 作为烈拳的进阶奖励版，提供破防+输出一体化选择。 | 与烈拳功能重叠；通过自损和玄品稀有度区分。 |

### 10.4 数值与复用性审查

| 审查项 | 结论 |
|------|------|
| **数值安全** | 黄品卡整体略强于初始卡但不直接复制升级卡；玄品强度集中在自损代价；地品只有 1 张且带消弭。 |
| **MVP 兼容** | 不要求新状态、不要求多目标、不要求抽牌、弃牌检索、保留、临时费用等复杂机制。 |
| **山野妖猴兼容** | 斗击牌仍会被灵猴闪避限制；永炎和易损提供绕开单一攻击节奏的奖励差异。 |
| **道痕兼容** | 九乌坠日可与祝融残焰叠永炎，但地品低概率+消弭避免每轮无限堆叠。体修金刚能缓冲自损，符修遗箓能提高见卡次数。 |
| **复用性** | 10 张卡均可用通用字段表达，后续迁移 JSON 或配置表时无需特殊结构。 |
| **扩展性** | 后续可补升级版、更多 Boss/事件天品池、低血量判定、涅槃回复等巫祝完整机制。 |

### 10.5 待开发接入建议

1. 先在 `DataDefs.cs` 中以硬编码方式加入上述 10 张卡，不引入配置表。
2. `RewardCardPool` 改为仅引用 `wx_r_001` ~ `wx_r_010`，不再引用初始卡。
3. 第一版可继续随机 3 选 1，不接入 rareOffset；若要按稀有度抽选，再接 §5 的正式概率。
4. 如果当前战斗逻辑尚未支持"消弭"，`祝融残焰` 需先暂时标记为一次性牌或延后接入。

### 10.6 待决策项

当前方案**不需要新增关键词**，也**不改变奖励概率机制**。以下内容暂不决策：

- 是否加入低血量触发、涅槃回复等巫祝完整机制。

### 10.7 巫祝 ACT1 Boss 天品奖励卡最小池
