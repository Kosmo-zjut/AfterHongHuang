## 0. 怪物池体系

对标杀戮尖塔的怪物生成规则。每关怪物按难度分为三个池：

| 池子 | 说明 | 出现时机 |
|:--:|------|------|
| **弱怪池** | 该关基础敌人，战力较低 | 第一大关（不周废墟）前 3 场；其余大关前 2 场 |
| **强怪池** | 战力较强的常规敌人 | 弱怪场次之后的所有普通战斗 |
| **精英池** | 高战力高回报 | 地图精英节点（另算，不进入弱/强顺序） |

### 奖励规则

每次击败敌人（普通/精英/Boss）：

| 奖励 | 说明 |
|------|------|
| **卡牌** | 3 选 1，含 rareOffset 概率补正。详见 [01-卡牌系统](./01-卡牌系统.md) §5 |
| **灵韵** | 游戏内货币（暂定），对标金币。普通少量、精英中等、Boss大量 |

## 三片区域的敌人生态

每片区域的敌人不是随机生成的——它们都是战后环境自然产生的"生态"。

### Act 1：不周废墟（地表残骸区）

共工撞断不周山后，天河倾泻、天火坠落、灵气紊乱——**这里变成了修士的黑森林**。

| 类型 | 敌人 | 逻辑 |
|------|------|------|
| 弱怪池 | **山野妖猴 / 碎石山精 / 掠灵散修** | 三个数据层遭遇，前三场普通战斗只从此池抽取 |
| 强怪池 | **不周残兵 / 符阵散修 / 山魈王** | 第四场普通战斗起可出现，每条有效路线至少出现一次 |
| 精英 | **十大妖圣残魂碎片**（随机） | 计蒙、白泽、英招等战死妖圣的执念——不是完整的意识，是一段**循环播放的临终记忆**，你走进那个区域就会被拉进去 |
| Boss | **相柳之骸（MVP）** | 第一轮先实现单体阶段转换 Boss；其余 5 个 Boss 保留在设计池 |

### Act 1 MVP 路线摘要

- 9 层分层 DAG：入口 → 3 层弱怪 → 4 层混合节点 → Boss。
- 每条路径恰好经过 3 场弱怪、至少 1 场强怪、至少 1 个灵脉和 1 个 Boss；商店为可选节点，实际路径允许 0~1 个。整张图至少生成 1 个、建议 2~3 个可达商店候选；每个 Layer 3 节点至少存在一条经过商店后到 Boss 的路径。
- Layer 4~7 每层至少包含 2 种节点类型和 1 个战斗节点；灵脉、商店、问号不得独占整层，同类非战斗节点不得沿边相邻。
- 地图边必须满足稳定顺序无反转的不变量；共享端点不算交叉，`StableOrder` 和 `GraphFingerprint` 属于图数据而非 UI 推断。
- 问号最多 1 个，商店最早 Layer 5、最晚 Layer 7，Boss 固定 Layer 8。
- 路线由 `RunSeed` 派生，同 seed、同规则版本、同角色得到同一张地图和节点内容。
- 完整连接约束、节点配额、商店和事件见 [11-第一大关设计](./11-第一大关设计.md)。

### Act 2：太阳残宫（天庭坠落区）

帝俊太一自爆后，整个妖族天庭从三十三天砸了下来，嵌在大地裂缝里。**这里还在燃烧**。

| 类型 | 敌人 | 逻辑 |
|------|------|------|
| 小怪 | **金乌残羽** | 九只被杀金乌的血液溅落处，生出了火元素生命体——它们不认识你是谁，只知道一切会动的东西都该烧掉 |
| 小怪 | **天兵俑** | 周天星斗大阵的守护傀儡。主人死了，但它们还在执行最后一条指令：**守护天庭**。而你现在踩在天庭的屋顶上 |
| 小怪 | **迷失的星辉** | 365杆星辰幡炸裂后，有些碎片还在和天上星辰共鸣，不定期释放无差别的冲击 |
| 精英 | **周天星斗阵碎片** | 残阵自行运转，随机抽取星辰之力攻击入侵者——它已经分不清敌我了 |
| Boss（3选1） | 详见 [09-Boss设计](./09-Boss设计.md) | 鲲鹏残魂 / 金乌怨影 / 帝俊残辉 |

### Act 3：都天神渊（祖巫葬地）

祖巫的鲜血浸透大地，形成了煞气浓度极高的深渊裂隙。**这里的时间是混乱的**。

| 类型 | 敌人 | 逻辑 |
|------|------|------|
| 小怪 | **煞气化形** | 纯粹由祖巫煞气凝聚的无意识战斗形态——是祖巫死前愤怒的"标本" |
| 小怪 | **巫族残念** | 不是鬼魂，更接近一段"录像"。走过某区域时触发一个死去的巫族战士临终画面——画面里的他可能会攻击你，因为他不分敌我了 |
| 小怪 | **被侵蚀的异兽** | 原本生活在深渊的远古生物，吸了千年煞气后变异 |
| 精英 | **祖巫执念**（随机） | 某一位祖巫的一缕残余意志（祝融之火/共工之水/玄冥之冰/强良之雷），已经不知道自己在做什么了 |
| Boss（3选1） | 详见 [09-Boss设计](./09-Boss设计.md) | 盘古残响 / 祝融炎冢 / 烛九阴时涡 |
