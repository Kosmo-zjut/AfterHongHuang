## 商人："行脚宝商"

### 身份

多宝道人（截教大师兄，通天教主座下首徒）在各地建立了一个松散的行商网络——**宝商**。他们奉行"宝物不认主，有缘者得之"的理念，在废墟中收集无主法宝并交易给合适的冒险者。

遗荒外围有低阶宝商出没——他们不敢深入，但会在最外层的不周废墟区摆摊收宝。

### 宝商服务

| 服务 | 说明 |
|------|------|
| **购买卡牌** | ACT1 展示 3 张不重复卡牌，按黄/玄/地品定价 |
| **购买法宝** | ACT1 预留 1 个法宝货架；法宝系统未接入时隐藏，不显示假商品 |
| **移除卡牌** | 支付灵韵从牌组中永久移除一张牌，首次 60，之后按次数递增 |
| **重列货架** | 支付 35 灵韵刷新一次卡牌/法宝库存，每个商店最多一次 |
| **离开商店** | 结束节点并返回地图，离开后不能再次进入购买 |

### 灵丹

宝商出售的回复品：

| 名称 | 效果 | 价格 |
|------|------|:--:|
| **聚灵丹** | 回复20%生命 | 40 |
| **续命丹** | 回复50%生命 | 80 |
| **妖兽内丹** | 永久+3生命上限 | 120 |

### ACT1 宝商规格

| 项目 | ACT1 规则 |
|------|------|
| 出现层 | Layer 5~7；整张图至少 1 个、建议 2~3 个可达商店候选；实际路径允许 0~1 个，最晚不晚于 Boss 前一层 |
| 卡牌库存 | 3 张；黄品 35~50、玄品 60~85、地品 100~140 |
| 法宝库存 | 1 件；普通 70~100、稀有 110~140；未接入时隐藏 |
| 除牌 | 每店 1 次；首次 60，`CardRemovalCount` 每增加 1 次价格 +20 |
| 重列货架 | 每店 1 次，35 灵韵；只改变未购买库存 |
| 随机来源 | `ShopSeed = Hash(ActSeed, "shop")`，再按 `NodeId` 派生；不受奖励抽取影响 |
| 购买状态 | 商品购买后标记已售，不能被新库存替换；取消除牌不扣费 |
| 离开规则 | 点击离开后写入 `ShopCompleted`，节点标记已访问；地图/套牌只读呼出层不能跳转节点 |

### 三层宝商

| 位置 | 出现 | 说明 |
|------|:--:|------|
| Act 1 不周废墟 | 图级至少 1 个、建议 2~3 个（Layer 5~7）；单条路径允许 0~1 个 | 真正的行脚宝商，多宝道人门下外门追随者 |
| Act 2 太阳残宫 | 概率（地图上有商店节点） | 同一位"宝商"——实力不合理的强，但从不解释 |
| Act 3 都天神渊 | 概率（地图上有商店节点） | 同上。极少数对话选项中可能漏出半句："师尊说这地方很有意思" |

> **彩蛋**：Act 3 的宝商可能无意中提到"师尊让我来看看"——暗示他是玄都大法师（太上老君唯一的亲传弟子），伪装成宝商在观察五个洪荒孤儿的旅程。不展开、不解释、不推动剧情。只是一个细节留给玩家自己去发现。
