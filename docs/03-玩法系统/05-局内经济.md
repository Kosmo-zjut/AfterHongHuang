## 货币

**灵石**——洪荒世界通用的货币和修炼资源。在遗荒中用于与宝商交易。

| 获取途径 | 数量 |
|------|:--:|
| 击败普通敌人 | 10-20 |
| 击败精英 | 25-35 |
| 击败 Boss | 50 |
| 宝箱节点 | 20-40 |
| 事件奖励 | 不定 |

## 商人："行脚宝商"

### 身份

多宝道人（截教大师兄，通天教主座下首徒）在各地建立了一个松散的行商网络——**宝商**。他们奉行"宝物不认主，有缘者得之"的理念，在废墟中收集无主法宝并交易给合适的冒险者。

遗荒外围有低阶宝商出没——他们不敢深入，但会在最外层的不周废墟区摆摊收宝。

### 宝商服务

| 服务 | 说明 |
|------|------|
| **购买卡牌** | 展示3-5张随机卡牌，每张不同价格 |
| **购买法宝** | 出售1-2件法宝（稀有/普通级，极低概率传说级） |
| **移除卡牌** | 支付灵石从牌组中永久移除一张牌（首次较便宜，逐次涨价） |
| **购买灵丹** | 少量回复药品 |

### 灵丹

宝商出售的回复品：

| 名称 | 效果 | 价格 |
|------|------|:--:|
| **聚灵丹** | 回复20%生命 | 40 |
| **续命丹** | 回复50%生命 | 80 |
| **妖兽内丹** | 永久+3生命上限 | 120 |

### 三层宝商

| 位置 | 出现 | 说明 |
|------|:--:|------|
| Act 1 不周废墟 | 固定（Boss前必有一个商店节点） | 真正的行脚宝商，多宝道人门下外门追随者 |
| Act 2 太阳残宫 | 概率（地图上有商店节点） | 同一位"宝商"——实力不合理的强，但从不解释 |
| Act 3 都天神渊 | 概率（地图上有商店节点） | 同上。极少数对话选项中可能漏出半句："师尊说这地方很有意思" |

> **彩蛋**：Act 3 的宝商可能无意中提到"师尊让我来看看"——暗示他是玄都大法师（太上老君唯一的亲传弟子），伪装成宝商在观察五个洪荒孤儿的旅程。不展开、不解释、不推动剧情。只是一个细节留给玩家自己去发现。
