## 总项目经理预审阻断

### P0-1 地图展开期间仍可能点击穿透

- `MapOverlayController` 根节点为 `MouseFilter=Ignore`。
- 实际阻断输入的 `_panel` 在展开动画中宽度从 `0` 增长到 `1600`。
- 动画期间 TopBar 以下未被 Panel 覆盖的区域仍可能点击到底层按钮、卡牌或节点页。
- 期望：从打开请求开始到关闭动画完成，TopBar 下缘至窗口底部始终存在完整输入阻断层；TopBar 本身保持可用。

### P0-2 服务节点“返回地图/离开”没有立即打开地图

- `LingmaiController.ReturnToMap()` 当前只提交 `Exited` 并刷新结果页，没有调用地图 overlay。
- `ShopController.LeaveShop()` 当前只提交结果并刷新商店页，没有调用地图 overlay。
- `EventController.ExecuteOption()` 当前完成后只刷新事件结果页，没有提供或自动触发明确的“继续/返回地图”入口。
- 期望：节点结算与地图显示职责分开；完成后保留结果页、操作按钮灰显，明确的“继续/返回地图”按钮只打开可交互地图 overlay。

### P0-3 Map / Deck / Settings 没有统一互斥协调器

- 各节点页仍分别把 TopBar 回调直接绑定到 `DeckViewer.Show`、`MapOverlayController.Open`、`SettingsHelper.Show`。
- 未发现统一 overlay 协调器；打开地图不会显式关闭套牌/设置，打开设置也不会显式关闭地图/套牌。
- 期望：同一时刻最多显示一个 Map/Deck/Settings overlay；重复点击当前入口关闭；Settings 模态阻断底层输入。

### P0-4 场景路由失败没有恢复原完成页状态

- `TryTransitionFromCompletedNode()` 在状态迁移失败时可以恢复快照。
- 但状态迁移成功后若 `NodeSceneRouter.TryGoTo()` 的场景切换失败，当前只执行 `AbortActiveNodeEntry()` 清理新节点，不能恢复原已完成节点、结果页上下文和可重试状态。
- 期望：状态迁移与场景路由属于同一事务；路由失败时恢复原完成页所需的 ActiveNode、结果状态、奖励状态和导航字段。

### P1-1 “随机角色”仍等于第一个已解锁角色

- `CharacterSelectController.OnAvatarPressed()` 的随机入口仍调用 `SelectFirstUnlockedCharacter()`。
- 这不满足任务卡中“从全部已解锁 Definition 随机选择”的要求。
- 期望：从当前 Definition 目录中收集全部已解锁且初始牌组有效的角色，再使用项目认可的随机入口选择；空集合显式失败。
