## 2. 游戏类型与核心玩法

**卡牌构筑 Roguelike**，参照杀戮尖塔2骨架：

- **5个可选角色**，各有独立卡池和专属法宝
- **三段旅程 + 最终Boss**，每段：小怪→精英→Boss
- **法宝系统**对应杀戮尖塔的"遗物"机制，获取洪荒传说中的各类灵宝
- 死亡 = 道心破碎，重新求道，完美契合 roguelike 重开叙事

### 2.1 叙事框架：向心旅程

巫妖大战的最后时刻，空间祖巫**帝江**引爆自身法则，战场上炸开了一道空间裂缝，吞噬了核心区域的一切。千年过去了，裂缝没有愈合——最近，裂缝深处**有东西在发出信号**。

五个"洪荒孤儿"听到了不同的召唤，但目标指向同一个方向。这不是爬塔，而是一趟**从边缘向核心收束的旅程**——所有人都在向战场最深处的那道裂缝走去。

### 2.3 三片区域的敌人生态

每片区域的敌人不是随机生成的——它们都是战后环境自然产生的"生态"。

#### Act 1：不周废墟（地表残骸区）

共工撞断不周山后，天河倾泻、天火坠落、灵气紊乱——**这里变成了修士的黑森林**。

| 类型 | 敌人 | 逻辑 |
|------|------|------|
| 小怪 | **山精野怪** | 灵气泄露吸引的低阶妖物，来吸食残存灵力 |
| 小怪 | **趁乱散修** | 废墟里捡垃圾的不止你一个，有些人不介意捡完你的再走 |
| 小怪 | **残兵怨魂** | 不周山倒塌时压死的巫妖两族士兵，怨气不散 |
| 精英 | **十大妖圣残魂碎片**（随机） | 计蒙、白泽、英招等战死妖圣的执念——不是完整的意识，是一段**循环播放的临终记忆**，你走进那个区域就会被拉进去 |
| Boss | **相柳之骸** | 九头蛇妖大巫相柳的尸体被废墟掩埋千年，残念还在重复死前的最后一个动作：守护巫族的领地 |

#### Act 2：太阳残宫（天庭坠落区）

帝俊太一自爆后，整个妖族天庭从三十三天砸了下来，嵌在大地裂缝里。**这里还在燃烧**。

| 类型 | 敌人 | 逻辑 |
|------|------|------|
| 小怪 | **金乌残羽** | 九只被杀金乌的血液溅落处，生出了火元素生命体——它们不认识你是谁，只知道一切会动的东西都该烧掉 |
| 小怪 | **天兵俑** | 周天星斗大阵的守护傀儡。主人死了，但它们还在执行最后一条指令：**守护天庭**。而你现在踩在天庭的屋顶上 |
| 小怪 | **迷失的星辉** | 365杆星辰幡炸裂后，有些碎片还在和天上星辰共鸣，不定期释放无差别的冲击 |
| 精英 | **周天星斗阵碎片** | 残阵自行运转，随机抽取星辰之力攻击入侵者——它已经分不清敌我了 |
| Boss | **鲲鹏残魂** | 妖师鲲鹏在巫妖大战中重伤逃往北冥，但它的**恶尸**被炸死在废墟里。这具被抛弃的恶尸吸收了一千年的残魂碎片，以为自己就是鲲鹏本人 |

#### Act 3：都天神渊（祖巫葬地）

祖巫的鲜血浸透大地，形成了煞气浓度极高的深渊裂隙。**这里的时间是混乱的**。

| 类型 | 敌人 | 逻辑 |
|------|------|------|
| 小怪 | **煞气化形** | 纯粹由祖巫煞气凝聚的无意识战斗形态——是祖巫死前愤怒的"标本" |
| 小怪 | **巫族残念** | 不是鬼魂，更接近一段"录像"。走过某区域时触发一个死去的巫族战士临终画面——画面里的他可能会攻击你，因为他不分敌我了 |
| 小怪 | **被侵蚀的异兽** | 原本生活在深渊的远古生物，吸了千年煞气后变异 |
| 精英 | **祖巫执念**（随机） | 某一位祖巫的一缕残余意志（祝融之火/共工之水/玄冥之冰/强良之雷），已经不知道自己在做什么了 |
| Boss | **盘古残响** | 十二都天神煞大阵残余能量凝聚的盘古虚影碎片——它只有盘古的万分之一力量，但那股"开天辟地"的原始意志还在 |

### 2.4 最终Boss：第十三人

帝江炸开的空间裂缝吞噬了数万尸体、祖巫精血、妖圣残魂。千年间，法则碎片、怨念、执念在那团混沌里自行重组。

**它没有名字，没有脸，没有独立的"自我"**——它是一个由太多东西拼凑成的存在。十二个祖巫的愤怒 + 帝俊的野心 + 太一的不甘 + 千万亡者的痛苦，全挤在一具身体里。

五个角色到达裂缝时，它刚刚破茧。它看着你们，用几百个人同时发出的声音问：**"你们……认识我吗？"**

#### 五套专属对话

| 角色 | 第十三人用谁的脸面对ta | 那句核心台词 |
|------|------|------|
| **巫祝** | 强良（雷之祖巫）的脸 | "你身上的气味……是我的……不对，是九凤的。**我不是让你回家了吗？**" |
| **盗宝者** | 帝俊的脸 | "你身上全是碎片……我的河图洛书、我的星辰幡……**捡得开心吗，垃圾佬？**" |
| **截教门徒** | 东皇太一的脸 | "通天的人……哼。你师尊有没有告诉你，当年他不来救我们，**是因为你们这些弟子太弱了？**" |
| **金乌遗孤** | 帝俊 + 父母（星辰幡执旗手）的脸交替出现 | "……你的父母跟我一起死了。他们喊了我的名字。你知道你父母最后一句话是什么吗？**是'妖皇万岁'。**"（然后它哭了——不是帝俊在哭，是父母的执念在里面哭） |
| **凡人** | 所有的脸轮流闪过，最后变成一张**空白的脸** | "……你没有味道。跟他们不一样。你是谁？……等等。你跟我一样。**里面……也是空的。**" |

> 战斗结束后，五个角色面对废墟做出不同的选择——但那一瞬间的沉默是相同的：旧时代终于死了。现在轮到我们了。

## 3. 世界观设定

### 3.1 时间定位：巫妖量劫之后

洪荒有三大劫（量劫）：

| 序号 | 劫名 | 结局 |
|:--:|------|------|
| 第一劫 | **龙汉初劫** | 龙、凤、麒麟三族覆灭，魔祖罗睺被鸿钧所灭 |
| 第二劫 | **巫妖量劫** ← 我们在其后 | 帝俊、太一陨落，十二祖巫几乎死绝，不周山倒，洪荒破碎 |
| 第三劫 | **封神之战**（尚未发生） | 阐截二教相争，封神榜出 |

> **本作时间**：巫妖量劫刚刚落幕约千年。洪荒大地一片废墟，旧时代的神话刚刚死去，新时代的秩序尚未建立。

### 3.2 巫妖量劫到底发生了什么

洪荒有两大超级势力：**妖族天庭**（掌天）和**巫族部落**（管地）。

**妖族**以太阳星中诞生的**帝俊、东皇太一**为首（本体为三足金乌），拜**鲲鹏**为妖师，统领万妖，拥有：
- **周天星斗大阵**（以河图洛书为阵眼，365杆星辰幡驱动，与诸天星辰共鸣）
- **混元河洛大阵**（帝俊掌控，可演化山川河洛困敌）

**巫族**以盘古精血所化的**十二祖巫**为首，不修元神只炼肉身，拥有：
- **十二都天神煞大阵**（十二祖巫合力可短暂凝聚盘古真身，超圣一击）

**导火索**：
1. 帝俊十子（十只金乌）被人教唆，十日齐出，大地焦枯
2. 大巫**夸父**逐日，被晒死
3. 大巫**后羿**射杀九只金乌，仅剩第十子**陆压**
4. 全面战争爆发

**终局**：
- 帝俊自爆、东皇太一自爆（混沌钟/东皇钟从此失踪）
- 十一祖巫陨落（帝江、祝融、句芒、蓐收、强良、奢比尸、天吴、弇兹、玄冥等战死）
- **共工**怒触不周山（天柱），天崩地裂，天河倒灌
- **后土**身化六道轮回，为巫族留下一线生机
- **女娲**炼五色石补天，斩神鳌四足为新的天柱
- 洪荒大陆崩碎为**四大部洲** + **海外十三岛**
- **妖族天庭覆灭**，妖族残余退守北俱芦洲
- **巫族几近灭绝**，血脉混入人族延续

#### 遗荒：世界中央的禁区

四大部洲中间不是海——原本是连接四洲的中央大陆。巫妖大战的核心区域就在这里。战后它被命名为**遗荒**，一个无主、无人管、也无人定居的禁区：

| 特征 | 说明 |
|------|------|
| **定位** | 洪荒大陆原本的中心，被四大部洲环绕 |
| **现状** | 天地灵气极度紊乱，法力不稳定 |
| **危险** | 空间碎片残留（帝江法则破裂）、祖巫煞气弥漫 |
| **归属** | 无主之地——没有任何教派在此立教，六圣补天后也未收复 |
| **生物** | 只有最外围有不周山溅射碎片形成的边缘生态区（低阶妖物、散修猎人） |

> 不是进不去——圣人当然进得去。但修仙是讲性价比的，没人在废墟里建道观。

### 6.3 法宝的核心设计理念

**参考杀戮尖塔遗物，但做出差异化的三点：**

1. **法宝持有者关联**：每件法宝都有明确的"原主人"历史（如"东皇太一的东皇钟残片"），强化世界观沉浸感。游戏中可以在"法宝图鉴"中查看每个法宝背后的洪荒故事。

2. **残缺即主题**：几乎所有顶级法宝都以"碎片/残片/残影"的形式出现——因为完整品已经被圣人收走或随主人一起毁灭了。你拿到的一直是"废墟中捡到的残余"，正呼应"洪荒之后"的主题。同一件法宝集齐多个碎片可以合成更强效果（集齐机制）。

3. **法宝反噬**：部分魔道法宝（弑神枪碎片等）使用时有代价——力量强大但会带来负面效果。对应洪荒设定中"法宝有灵，不是所有人都能驾驭"。

## 7. 五个可选角色（"洪荒孤儿"）

五个人来自截然不同的背景，但有一个共同点：**旧世界死了，新世界没有他们的位置**。他们都是被巫妖大战摧毁的旧秩序里的"边角料"。

### 7.1 巫祝（巫族后裔 / 血脉觉醒者）

| **为什么去** | 没有任何东西可以失去的人，反而什么都不怕。ta去裂缝，不是因为听到了什么召唤——ta什么都没听到。就是因为什么都没听到，才更想去 |
| **核心信念** | **"你们都说没有灵根不能修道。那我就去你们不敢去的地方，看看那里有什么。"** |
