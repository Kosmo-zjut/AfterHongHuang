# UI-FOCUS-SETTINGS-20260717

> 状态: Doing | 优先级: P0 | 创建: 2026-07-17

## 背景

用户窗口实测发现：战斗胜利奖励总面板未形成真正的模态焦点，手牌和测试按钮仍可浮到其上并接受交互；继续按钮位置不合理；地图卷轴展开后的内容贴右且留白不平衡；设置中的分辨率选择无实际效果。

## 冻结交互口径

1. 胜利奖励总面板出现后，面板以下的战斗 UI 必须整体降暗，且所有下层控件都不可交互，包括手牌、日志、结束回合和 Debug 测试按钮。只有总奖励面板及其上方 CardReward overlay 可接收输入。
2. 卡牌奖励 overlay 仍叠在奖励总面板上；关闭/跳过只关闭该 overlay，不改变总奖励面板焦点、奖励计划或下层状态。
3. 胜利总面板的“继续”移到面板右侧偏下的独立操作位，仍只打开当前节点页上的地图 overlay，不做结算、离场、奖励消费或页面清理。
4. 地图卷轴保持固定左起、向右展开；完全展开后，地图内容在可视区域居中，上下留白明显大于左右留白。横向滚轮和左键拖拽继续可用，不能回退为右侧抽屉。
5. 设置分辨率选择必须真正应用窗口/viewport 设置，并在取消、关闭、重开场景和重启后的行为上有明确口径；不支持的分辨率必须明确禁用或提示，禁止“显示已选择但实际未应用”。

## 分工

### 开发部

- 负责 `洪荒之后-code/` 的 UI 层级、输入阻断、布局、地图视口和设置分辨率实现。
- 优先查明现有奖励面板的 ZIndex、MouseFilter、输入路由与测试控件可点击原因，使用统一 modal/overlay 协调机制处理，而非逐个按钮临时禁用。
- 分辨率必须通过可复用的设置服务/配置入口处理，不把具体分辨率散落在按钮回调中。
- 扫描胜利、灵脉、商店、事件等节点页，确认新增的模态机制不破坏既有 overlay 互斥和“继续只开地图”语义。

### UI/UX 部

- 补充胜利面板模态层级、背景降暗、继续按钮锚点、地图全展开留白和分辨率切换后的界面适配验收口径。
- 不修改共享玩法状态或代码；指出 1920x1080 与至少一个低分辨率下的可读性/遮挡风险。

### QA 质量保证部

- 严格只读。先检查生产硬编码与隐藏按钮副作用，再验收：奖励总面板模态输入隔离、CardReward 叠层、继续纯开图、地图居中/拖拽/滚轮、分辨率真实生效及全节点页回归。
- 输入隔断若仅依赖视觉灰层而仍能点到下层，按 P0 失败。

## 验收标准

- 胜利总面板期间，点击或悬停手牌、日志、结束回合、Debug 按钮均无交互结果；背景明显降暗；总面板和 CardReward 可用。
- 继续按钮位于总面板右侧偏下，点击只开地图 overlay；关闭地图后回到原胜利页。
- 地图全开后内容不贴右；上下空白大于左右空白；滚轮和拖拽可达所有后续节点，拖拽不误点节点。
- 设置中选择分辨率后实际窗口/viewport 尺寸改变且 UI 无明显重叠；无效项不假成功。
- Debug/Release build、Godot headless、场景解析通过；用户完成窗口实测前不得标 Done。
