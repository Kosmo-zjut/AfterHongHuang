# 03-截教门徒（通天外门弟子 / 末路仙人）

> 版本: 0.4.0 | 状态: ✅ 已完成 | 来源: 游戏设定文档 §7.3

---

## 基本信息

| 属性 | 内容 |
|------|------|
| **身份** | 通天教主的外门弟子，截教"万仙来朝"中的万仙之一 |
| **状态** | 截教因为收了太多妖族残部，被阐教嘲笑是"畜生窝"。ta的很多同门在战争中当了炮灰。教主说"有教无类"，但ta开始怀疑这话到底是什么意思 |
| **卡牌流派** | 阵法·封印——叠加debuff，运筹帷幄的控场 |
| **代号** | 末路仙人 |

## 叙事动机

教主亲自对ta说："那东西不在天道推演的范围内。去看看。"这是教主第一次对ta说话。

## 核心信念

**"这不是截教的问题，是时代辜负了我们。"**

## 面对第十三人时

东皇太一的脸嘲讽"你们这些弟子太弱了"——截教门徒的回应是："我们确实弱。但我们还活着。你们强，你们死了。"
