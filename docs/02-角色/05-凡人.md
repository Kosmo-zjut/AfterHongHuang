# 05-凡人（人间求道者 / 无根之人）

> 版本: 0.4.0 | 状态: ✅ 已完成 | 来源: 游戏设定文档 §7.5

---

## 基本信息

| 属性 | 内容 |
|------|------|
| **身份** | 没有灵根、没有血脉、没有师承。出生在南赡部洲一个连名字都没有的小村庄 |
| **状态** | 巫妖大战时天上掉下来一块废墟碎片，砸平了半个村子。ta是幸存者，也是被遗忘者。有一个老疯子告诉ta：想修道？去死过最多人的地方 |
| **卡牌流派** | 道心·顿悟——高风险高收益，抽牌波动极大但上限最高 |
| **代号** | 无根之人 |

## 叙事动机

没有任何东西可以失去的人，反而什么都不怕。ta去裂缝，不是因为听到了什么召唤——ta什么都没听到。就是因为什么都没听到，才更想去。

## 核心信念

**"你们都说没有灵根不能修道。那我就去你们不敢去的地方，看看那里有什么。"**

## 面对第十三人时

所有的脸轮流闪过——最后变成一张空白的脸。第十三人说"你跟我一样，里面也是空的"——凡人没有回答。ta忽然意识到，自己和第十三人之间的区别是：自己选择了空，愿意去填满它；而第十三人是被强行塞满的。
