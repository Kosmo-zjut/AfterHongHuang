## 基本信息

| 属性 | 内容 |
|------|------|
| **身份** | 海外十三岛的散修猎人，无门无派无师承 |
| **状态** | 在废墟里刨食十年，捡到过金仙的断肢、妖圣的残羽，靠倒卖废墟废品发了财——但有钱改不了命，没有传承，永远是个捡垃圾的 |
| **卡牌流派** | 法宝·道具——法宝效果翻倍，大量消耗型法宝卡 |
| **代号** | 遗迹猎人 |

## 叙事动机

同行说裂缝深处有完整的法宝——不是碎片，是从没被捡过的。下面已经没有没捡过的东西了，上面还有。

## 核心信念

**"我不信捡垃圾捡不出一个道来。"**

## 面对第十三人时

帝俊的脸嘲笑ta"捡得开心吗，垃圾佬？"——盗宝者第一反应不是害怕，是愤怒："你活着的时候看不上我们散修，死了还看不上？"
