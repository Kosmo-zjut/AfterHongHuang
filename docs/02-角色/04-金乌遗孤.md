# 04-金乌遗孤（妖族幸存者 / 化形之妖）

---

## 基本信息

| 属性 | 内容 |
|------|------|
| **身份** | 帝俊麾下一对星辰幡执旗手的后代，一个小妖族 |
| **状态** | 从来没见过父母——父母随帝俊一同自爆的时候ta还在蛋里。ta只听说过"十大金乌""天庭辉煌"的传说，但越听越不对劲 |
| **卡牌流派** | 变化·吞噬——双形态切换，战斗中吞噬敌人获得临时能力 |
| **代号** | 化形之妖 |

## 叙事动机

最后一个见到帝俊的人消失在裂缝附近。ta要听到帝俊的遗言——"如果他们骗我们赴死呢？如果他们明知会输呢？"

## 核心信念

**"我要一个答案。哪怕答案让我恨他们。"**

## 面对第十三人时

父母的脸和帝俊的脸交替出现。它说出父母最后一句话是"妖皇万岁"的时候，金乌遗孤沉默了——ta不知道自己希望听到的是"我们爱你"还是"我们被利用了"。哭声不是帝俊的，是父母的执念在哭——这让ta更痛苦。
